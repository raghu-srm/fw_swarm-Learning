1. Why This Matters

Five aircraft are launched with slightly different airspeed commands, altitude targets and clock offsets. No ground station is in the loop and each aircraft hears only the neighbours within radio range. How can the swarm agree on one speed, one flight level, one mission clock using nothing but local exchanges? This is the consensus problem, the first dynamical block of the pipeline:

\[ \text{Graph topology} \rightarrow \underbrace{\text{consensus}}_{\text{this part}} \rightarrow \text{formation} \rightarrow \text{vehicle guidance} \rightarrow \text{autopilot} \]

Part 3 built \(L=D-A\) and showed that \((Lx)_i\) is UAV \(i\)'s local disagreement with its neighbours; Part 4 showed that the eigenvalues \(0=\lambda_1\le\lambda_2\le\dots\le\lambda_N\) encode connectivity. Here we feed the disagreement back as a velocity, \(\dot x=-kLx\), solve the resulting linear system exactly, and prove where it goes and how fast.

Input\(L=D-A\) and \((Lx)_i=\sum_{j\in\mathcal N_i}a_{ij}(x_i-x_j)\) (Part 3); \(\lambda_2\gt0\iff\) connected (Part 4); eigen-decomposition, matrix exponential (A1).
OutputWrite and solve the consensus law for any undirected swarm graph, predict the final value and the time constant \(1/(k\lambda_2)\), handle vector states, implement it in NumPy.
Used inPart 6 (sampling, delays, loss), Part 7 (directed links), Part 8 (pinning), Parts 9, 12, 13, 19.

2. The Consensus Protocol

Throughout this part the communication graph is undirected and weighted: if UAV \(i\) hears UAV \(j\) then \(j\) hears \(i\), with the same weight \(a_{ij}=a_{ji}\ge0\). UAV \(i\) carries a scalar state \(x_i(t)\) that it broadcasts to its neighbour set \(\mathcal N_i\).

Definition (consensus). The swarm reaches consensus if \(x_i(t)-x_j(t)\to0\) for every pair \((i,j)\), i.e. \(x(t)\to x^\ast\mathbf 1_N\) for some common value \(x^\ast\). It reaches average consensus if moreover \(x^\ast=\frac1N\sum_{j=1}^Nx_j(0)\).

The simplest local rule is move toward each neighbour at a rate proportional to the gap:

\[ \dot x_i=\sum_{j\in\mathcal N_i}a_{ij}\,(x_j-x_i)=-\sum_{j\in\mathcal N_i}a_{ij}\,(x_i-x_j)=-(Lx)_i . \]

The last step is the Part 3 identity. Stacking the \(N\) equations and inserting a common gain \(k\) (units \(\mathrm{s^{-1}}\) when the \(a_{ij}\) are dimensionless) gives the continuous-time consensus protocol:

\[ \boxed{\;\dot x=-kLx,\qquad x=\operatorname{col}(x_1,\dots,x_N),\quad k\gt0\;} \]
Interpretation: each UAV is pulled toward its neighbours by springs of stiffness \(ka_{ij}\) acting on the state difference. A neighbour with a larger value pulls the state up, a smaller one pulls it down; a UAV whose neighbours all agree with it does not move. UAV \(i\) uses only the \(x_j\) it actually receives.
Caution (sign). The gap is neighbour minus self, \((x_j-x_i)\). Writing \((x_i-x_j)\) gives \(\dot x=+kLx\), whose disagreement modes grow like \(e^{+k\lambda_it}\). The error is invisible when all states start equal.

2.1 Where can the swarm come to rest?

An equilibrium satisfies \(Lx=0\). For a connected undirected graph the kernel of \(L\) is exactly \(\operatorname{span}\{\mathbf 1\}\) (Part 4: \(\lambda_2\gt0\)), so the only equilibria are agreement states \(x=c\mathbf 1\). That fixes where a converging trajectory can end, not which \(c\) nor whether it converges. For that we solve the equation.

3. Solving \(\dot x=-Lx\): Spectral Decomposition

Take \(k=1\) (restore \(k\) at the end by replacing \(t\) with \(kt\)). The protocol is linear and time-invariant, so its unique solution is the matrix exponential (A1):

\[ x(t)=e^{-Lt}x(0),\qquad e^{-Lt}\stackrel{\text{def}}{=}\sum_{m=0}^{\infty}\frac{(-t)^m}{m!}L^m . \]

The series becomes transparent through the spectral theorem. Because the graph is undirected, \(L=L^T\), so \(L\) has real eigenvalues and an orthonormal set of eigenvectors (\(v_i^Tv_j=0\) for \(i\ne j\), \(\|v_i\|=1\)):

\[ L=\sum_{i=1}^N\lambda_i\,v_iv_i^T,\qquad v_1=\frac{\mathbf 1}{\sqrt N},\ \lambda_1=0 . \]

Step 1 — powers. \((v_iv_i^T)(v_jv_j^T)=v_i(v_i^Tv_j)v_j^T\) is zero for \(i\ne j\) and \(v_iv_i^T\) for \(i=j\), so \(L^2=\sum_i\lambda_i^2v_iv_i^T\) and by induction \(L^m=\sum_i\lambda_i^mv_iv_i^T\) for all \(m\ge0\) (for \(m=0\), \(\sum_iv_iv_i^T=I\) because the \(v_i\) form an orthonormal basis).

Step 2 — the exponential. Insert into the series and swap the sums:

\[ e^{-Lt}=\sum_{m=0}^\infty\frac{(-t)^m}{m!}\sum_{i=1}^N\lambda_i^mv_iv_i^T=\sum_{i=1}^N\Big(\sum_{m=0}^\infty\frac{(-\lambda_it)^m}{m!}\Big)v_iv_i^T=\sum_{i=1}^Ne^{-\lambda_it}\,v_iv_i^T . \]

Step 3 — modal coordinates. Apply to \(x(0)\) and set \(c_i=v_i^Tx(0)\), the component of the initial state along the \(i\)-th eigenvector:

\[ \boxed{\;x(t)=\sum_{i=1}^Nc_i\,e^{-\lambda_it}\,v_i,\qquad c_i=v_i^Tx(0)\;} \]

Each eigenvector is a disagreement pattern across the swarm and each pattern decays independently at its own rate \(\lambda_i\) — the picture Part 4 promised, \(\dot z_i=-\lambda_iz_i\) for \(z_i=v_i^Tx\).

Step 4 — the limit. For a connected graph \(\lambda_i\gt0\) for \(i\ge2\), so every term but the first vanishes; the first has \(\lambda_1=0\), \(v_1=\mathbf 1/\sqrt N\):

\[ e^{-Lt}\longrightarrow v_1v_1^T=\frac1N\mathbf 1\mathbf 1^T,\qquad x(t)\longrightarrow\frac1N\mathbf 1\mathbf 1^Tx(0)=\Big(\frac1N\sum_{j=1}^Nx_j(0)\Big)\mathbf 1 . \]
Theorem (average consensus on undirected graphs; Olfati-Saber & Murray 2004). If the undirected graph is connected, then under \(\dot x=-kLx\), \(k\gt0\), every state converges exponentially to the average of the initial states: \[ \boxed{\;x_i(t)\to\bar x(0)=\frac1N\sum_{j=1}^Nx_j(0)\ \ \text{for every }i,\qquad x(t)=\sum_{i=1}^Nc_ie^{-k\lambda_it}v_i\;} \] Proof: Steps 1–4 with \(t\) replaced by \(kt\) (\(e^{-kLt}\) has the same eigenvectors and exponents \(-k\lambda_it\)). If the graph is disconnected, \(\lambda_2=0\) and the same computation shows that each connected component converges to its own average.
Interpretation: the matrix exponential of a Laplacian is a weighted-averaging operator that becomes the exact averaging matrix \(\frac1N\mathbf 1\mathbf 1^T\) as \(t\to\infty\). The swarm computes a global average with purely local rules, and the last surviving pattern is the one belonging to \(\lambda_2\).

4. Conservation of the Average

The final value can be found without solving anything. Differentiate the sum of the states:

\[ \frac{d}{dt}\big(\mathbf 1^Tx\big)=\mathbf 1^T\dot x=-k\,\mathbf 1^TLx=-k\,(L^T\mathbf 1)^Tx=-k\,(L\mathbf 1)^Tx=0 , \]

using \(L=L^T\) and \(L\mathbf 1=0\) (Part 3). So the sum, hence the average \(\bar x=\mathbf 1^Tx/N\), is an invariant. With Section 2.1 (the only possible limits are \(c\mathbf 1\)) this forces \(c=\bar x(0)\): a one-line proof of the consensus value, given convergence.

\[ \boxed{\;\bar x(t)=\bar x(0)\ \text{ for all }t\quad(\text{undirected graphs})\;} \]
Caution (assumption). Invariance needs \(\mathbf 1^TL=0\), i.e. columns of \(L\) summing to zero; for undirected graphs that is the same as rows because \(L\) is symmetric. For directed graphs it fails: the swarm still agrees, but on a weighted average set by the left eigenvector of \(L\) (Part 7). Packet loss that is asymmetric in direction has the same effect (Part 6).

5. Disagreement Dynamics and Convergence Rate

Split the state into the part everyone agrees on and the rest. Define the disagreement vector

\[ \delta=x-\bar x\mathbf 1=\Big(I-\tfrac1N\mathbf 1\mathbf 1^T\Big)x=Px,\qquad P\stackrel{\text{def}}{=}I-\tfrac1N\mathbf 1\mathbf 1^T . \]

\(P\) is the orthogonal projector onto \(\mathbf 1^\perp=\{z:\mathbf 1^Tz=0\}\): \(P^2=P\), \(P^T=P\), \(P\mathbf 1=0\). Two facts make \(\delta\) easy: \(PL=L\) (because \(\mathbf 1^TL=0\)) and \(LP=L\) (because \(L\mathbf 1=0\)). Then

\[ \dot\delta=P\dot x=-kPLx=-kLx=-kLPx=-kL\delta . \]

The disagreement obeys the same equation as \(x\) but lives in \(\mathbf 1^\perp\), where the zero eigenvalue is absent. Expanding \(\delta(0)=\sum_{i\ge2}c_iv_i\) (its \(v_1\) component is zero by construction) and using orthonormality,

\[ \|\delta(t)\|^2=\Big\|\sum_{i\ge2}c_ie^{-k\lambda_it}v_i\Big\|^2=\sum_{i\ge2}c_i^2e^{-2k\lambda_it}\le e^{-2k\lambda_2t}\sum_{i\ge2}c_i^2=e^{-2k\lambda_2t}\|\delta(0)\|^2 , \]

since \(\lambda_i\ge\lambda_2\) for \(i\ge2\). Taking square roots:

\[ \boxed{\;\|\delta(t)\|\le e^{-k\lambda_2t}\,\|\delta(0)\|,\qquad \tau_c=\frac1{k\lambda_2},\qquad t_{2\%}\approx4\tau_c=\frac{4}{k\lambda_2}\;} \]
Interpretation: the algebraic connectivity \(\lambda_2\) is the guaranteed decay rate of disagreement and the gain \(k\) scales it. \(\tau_c=1/(k\lambda_2)\) is the one number to remember when sizing a consensus loop: after \(\tau_c\) at most \(37\%\) of the initial disagreement remains, after \(4\tau_c\) at most \(2\%\) (\(e^{-4}=0.018\)).
Note (tightness). Equality holds only when \(\delta(0)\parallel v_2\). A generic initial condition excites all modes; the fast ones (up to \(e^{-k\lambda_Nt}\)) vanish first and the trajectory then locks on to the \(\lambda_2\) pattern. Part 6 re-derives the bound by a Lyapunov argument that survives switching graphs.

6. Vector States: the Kronecker Form

A 2-D velocity, a 3-D reference position or the pair \((\cos\chi,\sin\chi)\) need \(x_i\in\mathbb R^n\). Apply the scalar protocol component by component and stack \(x=\operatorname{col}(x_1,\dots,x_N)\in\mathbb R^{Nn}\):

\[ \boxed{\;\dot x=-k\,(L\otimes I_n)\,x\;}\qquad L\otimes I_n=\begin{bmatrix}L_{11}I_n&\cdots&L_{1N}I_n\\ \vdots&&\vdots\\ L_{N1}I_n&\cdots&L_{NN}I_n\end{bmatrix} . \]

The eigenvalues of \(L\otimes I_n\) are the \(\lambda_i\), each repeated \(n\) times, with eigenvectors \(v_i\otimes e_m\) (A1: \((A\otimes B)(C\otimes D)=AC\otimes BD\)). Nothing changes: every component converges to its own initial average at rate \(k\lambda_2\), so \(x_i(t)\to\frac1N\sum_jx_j(0)\in\mathbb R^n\). In code use np.kron(L, np.eye(n)), or simply keep the states as an \(N\times n\) matrix \(X\) and write \(\dot X=-kLX\): each column is an independent scalar consensus.

7. Worked Example: Three-UAV Star

UAV 1 is linked to UAVs 2 and 3, which do not hear each other (Figure 1). From Parts 3–4,

\[ L=\begin{bmatrix}2&-1&-1\\-1&1&0\\-1&0&1\end{bmatrix},\quad \lambda=\{0,1,3\},\quad v_1=\tfrac1{\sqrt3}\begin{bmatrix}1\\1\\1\end{bmatrix},\ v_2=\tfrac1{\sqrt2}\begin{bmatrix}0\\1\\-1\end{bmatrix},\ v_3=\tfrac1{\sqrt6}\begin{bmatrix}2\\-1\\-1\end{bmatrix}. \]

Check by hand: \(L[0,1,-1]^T=[-1+1,\,1,\,-1]^T=1\cdot[0,1,-1]^T\) and \(L[2,-1,-1]^T=[6,-3,-3]^T=3\cdot[2,-1,-1]^T\); the three vectors are orthogonal and normalised. As patterns, \(v_2\) is "spoke 2 up, spoke 3 down, hub untouched" — a disagreement that must travel through the hub, hence slow — and \(v_3\) is "hub against both spokes", where every edge works, hence fast.

Initial states \(x(0)=[10,14,8]^T\) (say airspeed commands in m/s); average \(32/3=10.667\). Modal coefficients:

\[ c_1=\frac{32}{\sqrt3}=18.5,\qquad c_2=\frac{14-8}{\sqrt2}=4.24,\qquad c_3=\frac{20-14-8}{\sqrt6}=-0.816 . \]

Multiplying back, \(c_1v_1=10.667\,\mathbf 1\), \(c_2v_2=3\,[0,1,-1]^T\), \(c_3v_3=-\tfrac13[2,-1,-1]^T\). Collecting per UAV:

\[ \boxed{\begin{aligned} x_1(t)&=10.667-0.667\,e^{-3t},\\ x_2(t)&=10.667+3\,e^{-t}+0.333\,e^{-3t},\\ x_3(t)&=10.667-3\,e^{-t}+0.333\,e^{-3t}. \end{aligned}} \]

Sanity checks: at \(t=0\) the lines give \(10,14,8\); their sum is \(32\) for every \(t\) (the \(e^{-t}\) terms cancel, so do the \(e^{-3t}\) terms) — the invariant of Section 4. scipy.linalg.expm reproduces the closed form to machine precision (script in Section 9):

Observations. (i) The hub converges almost at once — its only disagreement is the fast \(\lambda_3=3\) mode — and sits at \(10.63\) after one second. (ii) The spokes carry the slow mode: their gap \(x_2-x_3=6e^{-t}\) shrinks with \(\tau_c=1/\lambda_2=1\) s. (iii) The bound is nearly tight because \(\delta(0)=[-0.667,3.333,-2.667]^T\) is almost parallel to \(v_2\). (v) With \(k=2\) every exponent doubles: \(\tau_c=0.5\) s, \(2\%\) in about \(2\) s.

8. Fixed-Wing Interpretation

8.1 What a fixed-wing swarm runs consensus on

  • Airspeed / ground-speed command \(V^c_{g,i}\): a formation must fly at one speed, and the average of the launch speeds is a sensible common choice. Must stay in \([V_{\min},V_{\max}]\) (8.3).
  • Altitude command \(h^c_i\): a common flight level; per-aircraft offsets \(\Delta h_i\) for de-confliction are added outside the consensus variable.
  • Mission clock / path parameter \(\zeta_i\): simultaneous arrival, time-coordinated path following (Part 19); its rate is bounded by the speed envelope.
  • Estimate of a reference \(\hat\xi_i\): every aircraft keeps a synchronised copy of the formation's virtual-structure state (Parts 8, 13); needs a leader term, plain consensus drifts.
  • Course \(\chi_i\): course alignment (Part 14) — not linear, see 8.2.

Positions are deliberately absent: aircraft in a formation must not agree on position. Formation control (Part 12) runs consensus on the displacement error \(p_i-r_i\) instead, which is why this scalar machinery carries over unchanged.

8.2 Angles do not average linearly

Courses live on a circle. Two aircraft with \(\chi_1=170^\circ\) and \(\chi_2=-170^\circ\) point almost the same way (\(20^\circ\) apart through south), yet linear consensus gives \(\frac12(170-170)=0^\circ\): due north, the opposite direction. Two correct options:

  • Unit-vector consensus. Run the Kronecker form on \(u_i=(\cos\chi_i,\sin\chi_i)\) and recover \(\chi_i=\operatorname{atan2}(u_{i,2},u_{i,1})\). For the example the average vector is \((-0.985,\,0)\), giving \(180^\circ\). The vector shrinks toward zero when courses are spread near \(180^\circ\) apart: renormalise before use and treat \(\|u\|\approx0\) as "no consensus".
  • Wrapped differences. If all neighbours are within \(\pm90^\circ\), use \(\dot\chi_i=k\sum_ja_{ij}\operatorname{wrap}(\chi_j-\chi_i)\) with \(\operatorname{wrap}(\cdot)\in(-\pi,\pi]\) — the small-angle form of the Kuramoto-type law \(\dot\theta_i=-k_\theta\sum_jw_{ij}\sin(\theta_i-\theta_j)\) of Part 19.

8.3 Envelope, actuator rate and the gain

A fixed-wing aircraft cannot hover while the swarm "thinks": it keeps flying at \(V_g\ge V_{\min}\), so \(4\tau_c\) seconds of consensus is \(4\tau_cV_g\) metres of track. The protocol also demands a rate of change, \(|\dot x_i|=k|\sum_ja_{ij}(x_j-x_i)|\le k\,d_i\,\Delta\), with \(\Delta\) the largest neighbour gap. If \(x_i\) is a speed command the autopilot can only follow it at the airframe's acceleration limit \(a_{\max}\), which caps the usable gain, \(k\le a_{\max}/(d_i\Delta)\). With \(a_{\max}=3\ \mathrm{m/s^2}\), \(d_i=2\) and a \(5\) m/s spread this gives \(k\le0.3\ \mathrm{s^{-1}}\), far below any stability limit. Keep the consensus variable itself unsaturated (so the invariant survives) and saturate only the command handed to the autopilot.

What each UAV broadcasts. At the communication rate \(1/T_s\) (5–10 Hz) UAV \(i\) sends \((i,\,t_{\text{stamp}},\,x_i)\): the shared variable only. Receivers evaluate \(\sum_ja_{ij}(x_j-x_i)\) with the latest value from each neighbour; \(a_{ij}\) can encode link quality, and timestamps tell a stale packet from a lost one (Part 6, Part 23).

High-speed note. The time constant is a property of the graph and the gain, not of the aircraft, but the distance flown during the transient scales with speed. With \(k\lambda_2=0.5\ \mathrm{s^{-1}}\) (\(\tau_c=2\) s, \(4\tau_c=8\) s) a 25 m/s UAV flies 50 m per time constant and 200 m to settle; at 60 m/s, 120 m and 480 m; at 200 m/s, 400 m and 1.6 km. Turn radius grows as \(V_g^2\) (Part 16), so relative to \(R_{\min}\) the transient shrinks with speed, but relative to leg length, spacing or sensor range it grows. A high-speed swarm needs a larger \(k\lambda_2\) — bounded by the sampling and delay limits of Part 6 — or must start consensus well before the manoeuvre that needs it.
Toward the CLAW This part supplies the agreement block of the unified control law: for every shared variable \(x_i\) (speed command, flight level, mission clock, reference estimate) UAV \(i\) computes \(\dot x_i=-k\sum_{j\in\mathcal N_i}a_{ij}(x_i-x_j)\) from the neighbour values it receives and hands the updated \(x_i\) to the layer below (formation guidance or vehicle command mapping). In the final CLAW this Laplacian term appears three times: as the distributed reference estimator (with a pinning term added in Part 8), as the displacement-error consensus inside formation control (Part 12), and as the time-coordination law of Part 19. Part 6 turns it into a sampled, lossy, delayed implementation; Part 7 removes the symmetry assumption.

9. Implementation & Demo

The script reproduces every number of Section 7: eigen-decomposition, modal coefficients, closed form, expm cross-check, the \(\lambda_2\) bound and a 10 Hz Euler run. SciPy is used only for expm; the Euler loop is the pure-NumPy fallback.

import numpy as np
from scipy.linalg import expm          # only for the cross-check

A = np.array([[0, 1, 1], [1, 0, 0], [1, 0, 0]], float)   # star: 1-2, 1-3
L = np.diag(A.sum(axis=1)) - A        # L = D - A
x0 = np.array([10.0, 14.0, 8.0])      # airspeed commands [m/s]
k = 1.0                               # consensus gain [1/s]

lam, V = np.linalg.eigh(L)            # orthonormal eigenvectors (L symmetric)
c = V.T @ x0                          # modal coordinates c_i = v_i^T x(0)
print("eigenvalues:", lam.round(4), " average:", x0.mean().round(4))
print("c1*v1 =", (c[0]*V[:, 0]).round(4))

def x_closed(t):                      # x(t) = sum_i c_i e^{-k lam_i t} v_i
    return V @ (c * np.exp(-k*lam*t))

for t in [0.5, 1.0, 2.0, 5.0]:        # closed form vs matrix exponential
    xe = expm(-k*L*t) @ x0
    print(f"t={t}: closed {x_closed(t).round(3)} expm {xe.round(3)} sum={xe.sum():.3f}")

P = np.eye(3) - np.ones((3, 3))/3     # projector onto 1-perp
d0 = P @ x0
for t in [1.0, 2.0, 3.0]:             # disagreement vs the lambda_2 bound
    dn = np.linalg.norm(P @ x_closed(t))
    print(f"t={t}: |delta|={dn:.4f} bound={np.exp(-k*lam[1]*t)*np.linalg.norm(d0):.4f}")

Ts, x = 0.1, x0.copy()                # pure-NumPy 10 Hz Euler run (limits: Part 6)
for n in range(int(5/Ts)):
    x = x - Ts*k*(L @ x)
print("Euler x(5):", x.round(4), " tau_c =", 1/(k*lam[1]))

10. Common Pitfalls

  • Sign of the gap. \(\dot x=-kLx\) converges, \(\dot x=+kLx\) diverges. Test with unequal initial states; equal states hide the error.
  • Assuming the average without symmetry. \(\bar x\) is invariant only if \(\mathbf 1^TL=0\). Directed links, asymmetric packet loss or \(a_{ij}\ne a_{ji}\) change the final value (Parts 6, 7).
  • Averaging angles. Linear consensus on \(\chi\) fails near the \(\pm180^\circ\) wrap; use unit vectors or wrapped differences (8.2).
  • Reading \(1/(k\lambda_2)\) as the exact settling time. It is the worst case over initial conditions; the fast modes vanish earlier. Conversely a disconnected graph (\(\lambda_2=0\)) never settles: each component converges to its own average.
  • Choosing \(k\) in continuous time only. Any \(k\gt0\) works in \(\dot x=-kLx\), but a sampled implementation is unstable once \(T_sk\lambda_N\ge2\) (Part 6), and the autopilot's rate limit caps \(k\) long before that (8.3).
  • Clipping the consensus state. Saturating \(x_i\) to the envelope breaks the invariant; clip the command, not the shared variable.
  • Vector states. With \(L\otimes I_n\) each eigenvalue appears \(n\) times; check connectivity on the \((n+1)\)-th smallest eigenvalue.

11. Exercises

Exercise 1 (derivation). Show that \(\delta(t)=Px(t)\) stays orthogonal to \(\mathbf 1\) for all \(t\), and that \(\|x(t)-x(\infty)\|=\|\delta(t)\|\) for a connected undirected graph.
Show solution
\(\mathbf 1^T\delta=\mathbf 1^TPx=(\mathbf 1^T-\frac1N\mathbf 1^T\mathbf 1\mathbf 1^T)x=(\mathbf 1^T-\mathbf 1^T)x=0\) for every \(x\). Since \(x(\infty)=\bar x(0)\mathbf 1\) and \(\bar x(t)=\bar x(0)\) (Section 4), \(x(t)-x(\infty)=x(t)-\bar x(t)\mathbf 1=\delta(t)\).
Exercise 2 (numeric). Path graph \(1\!-\!2\!-\!3\), \(x(0)=[0,6,3]^T\), \(k=1\). Find the eigen-decomposition of \(L\), the closed-form trajectory, and \(x(1)\), \(x(2)\).
Show solution
\(L=\begin{bmatrix}1&-1&0\\-1&2&-1\\0&-1&1\end{bmatrix}\), \(\lambda=\{0,1,3\}\), \(v_2=\frac1{\sqrt2}[1,0,-1]^T\), \(v_3=\frac1{\sqrt6}[1,-2,1]^T\). Average \(3\); \(c_2v_2=[-1.5,0,1.5]^T\), \(c_3v_3=[-1.5,3,-1.5]^T\), so \(x_1(t)=3-1.5e^{-t}-1.5e^{-3t}\), \(x_2(t)=3+3e^{-3t}\), \(x_3(t)=3+1.5e^{-t}-1.5e^{-3t}\). Hence \(x(1)=[2.374,\,3.149,\,3.477]^T\), \(x(2)=[2.793,\,3.007,\,3.199]^T\) (checked with expm). The middle UAV carries only the fast mode: the hub effect again.
Exercise 3 (weights). Keep the star of Section 7 but make link 1–2 twice as strong: \(a_{12}=a_{21}=2\), \(a_{13}=a_{31}=1\). Eigenvalues, final value and time constant for \(k=1\)?
Show solution
\(L=\begin{bmatrix}3&-2&-1\\-2&2&0\\-1&0&1\end{bmatrix}\), eigenvalues \(\{0,\,1.268,\,4.732\}\). The graph is still undirected, so the final value is still the plain average \(10.667\) (simulated \(x(20)=[10.667,10.667,10.667]^T\)): weights change the rate, not the value. Time constant \(1/\lambda_2=0.789\) s instead of \(1\) s.
Exercise 4 (Kronecker). Two UAVs exchange 2-D positions \(p_1(0)=(0,0)\) m, \(p_2(0)=(100,40)\) m and run \(\dot p=-(L\otimes I_2)p\) with \(L=\begin{bmatrix}1&-1\\-1&1\end{bmatrix}\). Eigenvalues of \(L\otimes I_2\), \(p(0.5)\) and the limit?
Show solution
Eigenvalues \(\{0,0,2,2\}\). Each coordinate is a two-node consensus with \(\lambda_2=2\): \(p_1(t)=(50,20)(1-e^{-2t})\), \(p_2(t)=(50,20)(1+e^{-2t})\). At \(t=0.5\): \(p_1=(31.6,\,12.6)\), \(p_2=(68.4,\,27.4)\) m (expm: \([31.606,12.642,68.394,27.358]\)). Both converge to the midpoint \((50,20)\) m: a rendezvous, which is why raw-position consensus is not a formation law.
Exercise 5 (design). On the star of Section 7 the shared variable is an airspeed command. Choose \(k\) for a \(2\%\) settling time of \(2\) s, then compute the initial rate demanded of the hub. Acceptable for \(a_{\max}=3\ \mathrm{m/s^2}\)?
Show solution
\(4/(k\lambda_2)=2\Rightarrow k=2\ \mathrm{s^{-1}}\). Hub rate at \(t=0\): \(k|(14-10)+(8-10)|=2\times2=4\ \mathrm{m/s^2}\gt a_{\max}\). Either slow the loop (\(k=1.5\): \(3\ \mathrm{m/s^2}\), \(t_{2\%}=2.67\) s) or saturate the command and accept a transient that is no longer the linear one analysed here. For comparison, a 5-UAV ring has \(\lambda_2=2-2\cos(2\pi/5)=1.382\), \(\lambda_N=3.618\), \(\tau_c=0.724\) s at \(k=1\) (the demo's values).

12. Key Takeaways & Formula Sheet

  • Protocol: \(\dot x_i=k\sum_{j\in\mathcal N_i}a_{ij}(x_j-x_i)\), i.e. \(\boxed{\dot x=-kLx}\); vector states \(\boxed{\dot x=-k(L\otimes I_n)x}\).
  • Solution: \(\boxed{x(t)=e^{-kLt}x(0)=\sum_ic_ie^{-k\lambda_it}v_i,\ c_i=v_i^Tx(0)}\) with orthonormal eigenvectors of the symmetric \(L\).
  • Limit (connected undirected graph): \(e^{-kLt}\to\frac1N\mathbf 1\mathbf 1^T\), so \(\boxed{x_i(t)\to\bar x(0)=\frac1N\sum_jx_j(0)}\): average consensus.
  • Invariant: \(\boxed{\frac{d}{dt}\mathbf 1^Tx=0}\) because \(L=L^T\) and \(L\mathbf 1=0\).
  • Disagreement \(\delta=Px\), \(\dot\delta=-kL\delta\), \(\boxed{\|\delta(t)\|\le e^{-k\lambda_2t}\|\delta(0)\|}\), \(\boxed{\tau_c=1/(k\lambda_2)}\), \(t_{2\%}\approx4\tau_c\).
  • Star example: \(\lambda=\{0,1,3\}\), \(x_2-x_3=6e^{-t}\), hub settles as \(e^{-3t}\); \(2\%\) at \(3.89\) s.
  • Fixed-wing: consensus on speed, level, clock, reference estimate — never raw position; angles via unit vectors; \(k\le a_{\max}/(d_i\Delta)\); transient distance \(4\tau_cV_g\) grows with speed.
