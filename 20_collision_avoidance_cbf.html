1. Why This Matters

Everything the swarm layer has produced so far — consensus (Parts 5–9), formation laws (Parts 12–13), flocking (Part 14), vector-field and coordinated path following (Parts 18–19) — was designed for performance: converge to the slot, hold the spacing, arrive on time. None of it carries a hard guarantee that two aircraft will never come closer than a safety distance \(d_s\). The repulsion term of flocking is a soft potential; a displacement-based formation law happily drives two UAVs through each other during a reconfiguration; a guidance law has no idea the neighbour exists. In a fixed-wing swarm a near miss is a mid-air collision, so we need a last line of defence that is cheap enough to run at the guidance rate on every aircraft, decentralised, and provable.

\[ \text{nominal command } u_i^{\mathrm{nom}} \ \text{(formation / guidance)} \rightarrow \boxed{\text{safety filter (CBF-QP)}} \rightarrow u_i^\ast \rightarrow \text{vehicle command mapping } (V_g^c,\chi^c) \rightarrow \text{autopilot} \]

The tool is the control barrier function (CBF). It turns "stay at least \(d_s\) apart" into a linear inequality on the input, and the safety filter into a tiny quadratic programme (QP) that changes the nominal command by the smallest amount that keeps the inequality true. For a single pair of aircraft the QP has a closed-form solution — one dot product and one max.

2. Safe Sets, Forward Invariance and Nagumo's Theorem

Consider a control-affine system with state \(x\in\mathbb R^n\) and input \(u\in U\subseteq\mathbb R^m\),

\[ \dot x = f(x) + g(x)\,u, \]

with \(f,g\) locally Lipschitz. Safety is encoded as a set the state must never leave.

Definition (safe set). Let \(h:\mathbb R^n\to\mathbb R\) be continuously differentiable. The safe set is \[ \mathcal C=\{x: h(x)\ge 0\},\qquad \partial\mathcal C=\{x:h(x)=0\},\qquad \operatorname{Int}\mathcal C=\{x:h(x)\gt 0\}. \] \(\mathcal C\) is forward invariant under a feedback \(u=k(x)\) if \(x(0)\in\mathcal C\) implies \(x(t)\in\mathcal C\) for all \(t\ge 0\).

For a pair of UAVs the natural choice is \(h_{ij}=\|p_i-p_j\|^2-d_s^2\): the state is safe exactly when the pair is at least \(d_s\) apart. The question is: which inputs keep the state inside \(\mathcal C\)? The classical answer only looks at the boundary.

Theorem (Nagumo, 1942; see Blanchini 1999). Let \(\dot x=F(x)\) with \(F\) locally Lipschitz, let \(\mathcal C=\{h\ge0\}\) be closed with \(\nabla h(x)\neq0\) on \(\partial\mathcal C\). Then \(\mathcal C\) is forward invariant if and only if \[ \dot h(x)=\nabla h(x)^T F(x)\ \ge\ 0\qquad\text{for all } x\in\partial\mathcal C . \] Proof idea: if \(\dot h\lt0\) at a boundary point, the solution through it has \(h(t)\lt0\) for small \(t\gt0\) and leaves \(\mathcal C\). Conversely, if the vector field never points outward on the boundary (it lies in the tangent cone), no trajectory can cross it; the "if" direction uses uniqueness of solutions and is the substantive part of Nagumo's work.
Interpretation: safety is a statement about the boundary only. Inside the safe set you may do anything; on the boundary the velocity must not point outward. CBFs extend this to a condition that is active before the boundary is reached, so that bounded inputs have time to act.

3. Control Barrier Functions and the CBF-QP

Along the control-affine system, the derivative of \(h\) is affine in the input. With the Lie-derivative notation \(L_fh=\nabla h^Tf\) and \(L_gh=\nabla h^Tg\) (a row vector of length \(m\)),

\[ \dot h(x,u)=L_fh(x)+L_gh(x)\,u . \]
Definition (control barrier function; Ames, Xu, Grizzle & Tabuada 2017). Let \(\mathcal C=\{h\ge0\}\subseteq\mathcal D\) with \(\mathcal D\) open. \(h\) is a control barrier function on \(\mathcal D\) if there exists an extended class-\(\mathcal K_\infty\) function \(\alpha\) (continuous, strictly increasing, \(\alpha(0)=0\)) such that \[ \sup_{u\in U}\big[L_fh(x)+L_gh(x)\,u\big]\ \ge\ -\alpha\big(h(x)\big)\qquad\forall x\in\mathcal D . \] The set of inputs that satisfy the inequality at \(x\) is \(K_{\mathrm{cbf}}(x)=\{u\in U: L_fh+L_gh\,u\ge-\alpha(h)\}\).

Read the inequality as a speed limit on leaving the safe set: \(h\) may decrease, but no faster than \(\alpha(h)\), and the allowed rate shrinks to zero exactly on the boundary. That is what makes the condition enforceable with bounded inputs: the braking starts early.

Theorem (Ames et al. 2017, Thm. 2). If \(h\) is a CBF on \(\mathcal D\) and \(\nabla h\neq0\) on \(\partial\mathcal C\), then any locally Lipschitz feedback \(u=k(x)\) with \(k(x)\in K_{\mathrm{cbf}}(x)\) renders \(\mathcal C\) forward invariant. If moreover \(\mathcal D\supset\mathcal C\), then \(\mathcal C\) is asymptotically stable in \(\mathcal D\) (trajectories that start slightly unsafe return).
Proof sketch for the linear choice \(\alpha(h)=\gamma h\), \(\gamma\gt0\): along the closed loop \(\dot h\ge-\gamma h\). By the comparison lemma \(h(t)\ge h(0)e^{-\gamma t}\). If \(h(0)\ge0\) then \(h(t)\ge0\) for all \(t\): \(\mathcal C\) is invariant. If \(h(0)\lt0\) then \(h(t)\to0^-\) exponentially: \(\mathcal C\) is attractive. On the boundary the condition reduces to \(\dot h\ge0\), i.e. Nagumo.

3.1 The CBF-QP safety filter

A nominal controller \(u^{\mathrm{nom}}(x)\) (formation, guidance, a pilot) is given. We want the closest input that is safe:

\[ \boxed{\;u^\ast(x)=\arg\min_{u\in U}\ \tfrac12\|u-u^{\mathrm{nom}}(x)\|^2 \quad\text{s.t.}\quad L_fh(x)+L_gh(x)\,u\ \ge\ -\alpha\big(h(x)\big)\;} \]

With box input bounds \(U=\{u_{\min}\le u\le u_{\max}\}\) this is a strictly convex QP with \(m\) variables and \(1+2m\) linear constraints, one per barrier plus the bounds (Ames et al. 2017; tutorial in Ames et al. 2019). Several barriers (several neighbours, obstacles, a geofence) simply add rows. The solution \(u^\ast(x)\) is Lipschitz wherever the QP is feasible, so the theorem applies.

Interpretation: the filter is minimally invasive. Far from danger the constraint is slack and \(u^\ast=u^{\mathrm{nom}}\); the formation law is untouched. The constraint only bites when \(h\) is about to decrease faster than \(\alpha(h)\) allows, and then it changes the command by the smallest vector that restores the inequality.
Two assumptions that are easy to forget. (i) The barrier must have relative degree one: \(L_gh\neq0\), otherwise the constraint does not contain \(u\) at all (Section 5 fixes this for double integrators and Section 7 for turn-rate inputs). (ii) With input bounds the QP can be infeasible; the definition requires the supremum over \(U\) to satisfy the inequality everywhere in \(\mathcal D\), which is a design condition on \(\alpha\) and \(d_s\), not something the solver checks for you.

4. The Pairwise Barrier: Decentralised Split and Closed-Form Filter

4.1 Single-integrator UAVs

Take velocity-commanded UAVs \(\dot p_i=u_i\), \(p_i\in\mathbb R^2\), and the pair barrier

\[ h_{ij}(p)=\|p_i-p_j\|^2-d_s^2,\qquad \dot h_{ij}=2(p_i-p_j)^T(\dot p_i-\dot p_j)=2(p_i-p_j)^T(u_i-u_j). \]

Here \(f=0\), \(L_gh_{ij}=[\,2(p_i-p_j)^T,\ -2(p_i-p_j)^T\,]\) acting on \((u_i,u_j)\). The centralised CBF constraint with \(\alpha(h)=\gamma h\) is

\[ 2(p_i-p_j)^T(u_i-u_j)\ \ge\ -\gamma\,h_{ij}. \]

A centralised solver could impose this on the pair. On board UAV \(i\) we only control \(u_i\), and we do not know what \(u_j\) will be this sample. The fix of Wang, Ames & Egerstedt (2017) is to split the budget in half: each UAV promises to supply half of the required rate.

\[ \boxed{\;2(p_i-p_j)^Tu_i\ \ge\ -\tfrac12\gamma\,h_{ij}\;}\qquad\text{and}\qquad 2(p_j-p_i)^Tu_j\ \ge\ -\tfrac12\gamma\,h_{ij}. \]

Adding the two decentralised constraints gives back the centralised one, so if both UAVs satisfy their own half the pair is safe — without any communication of commands; UAV \(i\) only needs \(p_j\) (from the state broadcast of Part 15). The split is conservative: both might be able to do more. Wang et al. use \(\alpha(h)=\gamma h^3\), which is less restrictive far away and sharper near the boundary; the linear \(\gamma h\) used here is simpler to tune.

Convention. The constraint for UAV \(i\) is written as \(a_{ij}^Tu_i\ge b_{ij}\) with \(a_{ij}=2(p_i-p_j)\) and \(b_{ij}=-\tfrac12\gamma h_{ij}\). Note \(a_{ij}\) points away from the neighbour; the inequality forbids moving toward the neighbour faster than \(\gamma h_{ij}/(4\|p_i-p_j\|)\). Do not confuse this \(a_{ij}\) with the adjacency weight of Part 2.

4.2 Closed-form solution with one active constraint

For one neighbour the filter is the Euclidean projection of \(u^{\mathrm{nom}}\) onto the half-space \(\{u:a^Tu\ge b\}\). Derive it from the KKT conditions (A1): with multiplier \(\lambda\ge0\),

\[ u-u^{\mathrm{nom}}-\lambda a=0,\qquad \lambda\,(a^Tu-b)=0,\qquad a^Tu\ge b. \] If \(a^Tu^{\mathrm{nom}}\ge b\) take \(\lambda=0\). Otherwise the constraint is active, \(a^T(u^{\mathrm{nom}}+\lambda a)=b\), so \(\lambda=(b-a^Tu^{\mathrm{nom}})/\|a\|^2\gt0\). Both cases: \[ \boxed{\;u^\ast=u^{\mathrm{nom}}+\frac{\max\big(0,\ b-a^Tu^{\mathrm{nom}}\big)}{\|a\|^2}\,a\;} \]
Interpretation: the correction is always along \(a\), i.e. directly away from the neighbour, and its size is the constraint violation divided by \(\|a\|^2\). Nothing is added to the component of \(u^{\mathrm{nom}}\) perpendicular to the line of sight.

4.3 Several neighbours

With \(|\mathcal N_i|\) neighbours the QP has \(|\mathcal N_i|\) half-plane rows (plus bounds) and no closed form, but it stays a two- or three-variable strictly convex QP. Any QP solver works (OSQP, quadprog; cvxpy for prototyping). The pure-NumPy fallback used in Section 8 is Hildreth's dual coordinate ascent (Hildreth 1957): write \(u=u^{\mathrm{nom}}+\sum_k\lambda_ka_k\), then sweep \(\lambda_k\leftarrow\max\{0,\lambda_k+(b_k-a_k^Tu)/\|a_k\|^2\}\) until the multipliers stop changing. Each sweep is one projection per constraint, so it reduces to the closed form above when only one row is active; for three crossing UAVs it matched SciPy's SLSQP solution to \(10^{-8}\) in the verification run.

4.4 When does the filter switch on?

For an exact head-on encounter at speed \(V\) each, the closing rate is \(2V\), \(\dot h=-4Vr\) at range \(r\), and the constraint \(\dot h\ge-\gamma h\) first becomes active at

\[ 4Vr=\gamma\,(r^2-d_s^2)\quad\Longrightarrow\quad r_{\mathrm{act}}=\frac{2V}{\gamma}+\sqrt{\frac{4V^2}{\gamma^2}+d_s^2}. \]

For \(V=20\) m/s, \(\gamma=0.5\) s\(^{-1}\), \(d_s=50\) m this gives \(r_{\mathrm{act}}=174\) m: a small \(\gamma\) means an early, gentle intervention; a large \(\gamma\) means a late, hard one. Section 7 turns this into a design rule for aircraft that cannot brake.

5. Double Integrators: the High-Order CBF

With acceleration inputs, \(\dot p_i=v_i,\ \dot v_i=u_i\) (the model of Part 9), write \(\Delta p=p_i-p_j\), \(\Delta v=v_i-v_j\), \(\Delta u=u_i-u_j\). The same barrier gives

\[ \dot h=2\Delta p^T\Delta v\quad(\text{no input: relative degree }2),\qquad \ddot h=2\|\Delta v\|^2+2\Delta p^T\Delta u . \]

\(L_gh=0\), so the CBF condition of Section 3 is empty. The remedy (exponential CBFs, Nguyen & Sreenath 2016; high-order CBFs, Xiao & Belta 2019/2022) is to make the first-order condition itself a barrier:

\[ \psi_0=h,\qquad \psi_1=\dot\psi_0+\alpha_1\psi_0=2\Delta p^T\Delta v+\alpha_1h,\qquad \text{require}\quad \dot\psi_1\ \ge\ -\alpha_2\,\psi_1 . \]
Theorem (high-order CBF, Xiao & Belta 2022, Thm. 4, specialised to relative degree 2 and linear class-\(\mathcal K\) functions). Let \(\mathcal C_0=\{\psi_0\ge0\}\), \(\mathcal C_1=\{\psi_1\ge0\}\). If \(x(0)\in\mathcal C_0\cap\mathcal C_1\) and the input satisfies \(\dot\psi_1\ge-\alpha_2\psi_1\) for all \(t\), then \(\mathcal C_0\cap\mathcal C_1\) is forward invariant; in particular \(h(t)\ge0\). Proof sketch: apply the comparison lemma twice. \(\dot\psi_1\ge-\alpha_2\psi_1\) and \(\psi_1(0)\ge0\) give \(\psi_1(t)\ge0\), i.e. \(\dot h\ge-\alpha_1h\); with \(h(0)\ge0\) this gives \(h(t)\ge0\).

Now expand the condition. Since \(\dot\psi_1=\ddot h+\alpha_1\dot h\),

\[ 2\|\Delta v\|^2+2\Delta p^T\Delta u+2\alpha_1\Delta p^T\Delta v\ \ge\ -\alpha_2\big(2\Delta p^T\Delta v+\alpha_1h\big), \] \[ \boxed{\;2\Delta p^T(u_i-u_j)\ \ge\ -2\|\Delta v\|^2-2(\alpha_1+\alpha_2)\,\Delta p^T\Delta v-\alpha_1\alpha_2\,h\;} \]

and the decentralised half for UAV \(i\) (same argument as Section 4):

\[ \boxed{\;2\Delta p^Tu_i\ \ge\ -\|\Delta v\|^2-(\alpha_1+\alpha_2)\,\Delta p^T\Delta v-\tfrac12\alpha_1\alpha_2\,h\;} \]
Interpretation of the three terms. \(-\|\Delta v\|^2\) is the "centrifugal" term: relative motion of any kind makes \(\ddot h\) positive, so it relaxes the constraint (the pair is sliding past each other). \(-(\alpha_1+\alpha_2)\Delta p^T\Delta v\) is positive when closing (\(\Delta p^T\Delta v\lt0\)) and demands deceleration proportional to the closing rate. \(-\tfrac12\alpha_1\alpha_2h\) is the usual slack that vanishes on the boundary. The constraint is again linear in \(u_i\) with normal \(a=2\Delta p\), so the closed form of Section 4.2 applies unchanged — only \(b\) is different.
Initial condition. The theorem needs \(\psi_1(0)\ge0\): the pair must not already be closing faster than \(\alpha_1h/(2\|\Delta p\|)\). If the filter is switched on in a state with \(\psi_1\lt0\), the constraint still pushes \(\psi_1\) back toward zero (attractivity), but \(h\ge0\) is not guaranteed during the recovery. Choose \(\alpha_1\) so that \(\psi_1\ge0\) holds at the communication range for the largest expected closing speed.

5.1 The braking-distance barrier

An alternative that encodes the input bound explicitly (Wang, Ames & Egerstedt 2017, Sec. IV; also Borrmann et al. 2015) asks that the relative stopping distance fits in the gap. If each UAV can decelerate at \(a_{\max}\), the relative deceleration is \(2a_{\max}\) and a closing speed \(v_c=-\Delta p^T\Delta v/\|\Delta p\|\) needs \(v_c^2/(4a_{\max})\) metres to stop. Hence

\[ h_{\mathrm{br}}=\sqrt{4a_{\max}\big(\|\Delta p\|-d_s\big)}+\frac{\Delta p^T\Delta v}{\|\Delta p\|}\ \ge 0 \iff \|\Delta p\|-d_s\ \ge\ \frac{v_c^2}{4a_{\max}}. \]

This \(h_{\mathrm{br}}\) depends on \(\Delta v\), so it has relative degree one in \(u\) and the ordinary CBF-QP applies. For the example below (\(a_{\max}=5\) m/s\(^2\), closing at 40 m/s) the stopping distance is 80 m, so at 120 m range the braking barrier is already violated (\(h_{\mathrm{br}}=-2.58\)); a filter must act well before that, which is exactly what the HOCBF does.

7. Fixed-Wing Interpretation

7.1 Relative degree and the look-ahead point

The command-level aircraft model of Part 15 in the horizontal plane is \(\dot p_i=V_{g,i}\hat t_i\), \(\dot\chi_i=\omega_i\), with \(\hat t_i=(\cos\chi_i,\sin\chi_i)\) and \(\hat n_i=(-\sin\chi_i,\cos\chi_i)\). For the pair barrier \(\dot h=2\Delta p^T(V_{g,i}\hat t_i-V_{g,j}\hat t_j)\): the speed enters directly (relative degree one) but the turn rate does not (relative degree two). Since speed is the input we can least afford to use, the barrier must be made to see \(\omega\). The standard trick is to control a look-ahead point \(\tilde p_i=p_i+\ell\hat t_i\) a distance \(\ell\) ahead of the nose (Olfati-Saber's near-identity diffeomorphism, 2002). Using \(\mathrm d\hat t/\mathrm dt=\omega\hat n\),

\[ \dot{\tilde p}_i=V_{g,i}\hat t_i+\ell\,\omega_i\hat n_i=R(\chi_i)\begin{bmatrix}V_{g,i}\\ \ell\,\omega_i\end{bmatrix} \quad\Longrightarrow\quad \tilde u_i:=\dot{\tilde p}_i\ \text{is a free 2-D vector.} \]

(Verified numerically in part20_fixedwing.py.) So apply the single-integrator filter of Section 4 to the look-ahead points with inflated distance \(\tilde d_s=d_s+2\ell\) — because \(\|p_i-p_j\|\ge\|\tilde p_i-\tilde p_j\|-\ell\|\hat t_i-\hat t_j\|\ge\|\tilde p_i-\tilde p_j\|-2\ell\) — and map back: \(V_{g,i}^c=\hat t_i^T\tilde u_i\), \(\omega_i^c=\hat n_i^T\tilde u_i/\ell\). The speed envelope and turn-rate limit become a box on \(z=(V_g,\ell\omega)\), and since \(\|R(\chi)z-\tilde u^{\mathrm{nom}}\|=\|z-R(\chi)^T\tilde u^{\mathrm{nom}}\|\) the QP in \(z\) is still a two-variable box-constrained QP with one half-plane per neighbour.

7.2 Turn-rate-only filter and the cost of saturation

If speed is held at its nominal value and only \(\omega\) is filtered, the constraint \(a^T\tilde u\ge b\) becomes scalar: \(c\,\omega\ge b'\) with \(c=\ell\,a^T\hat n\), \(b'=b-V_ga^T\hat t\), and the closed form of Section 4.2 in one dimension is \(\omega^\ast=\omega^{\mathrm{nom}}+\max(0,b'-c\,\omega^{\mathrm{nom}})\,c/c^2\), followed by clipping to \(\pm\omega_{\max}\). Clipping is where the guarantee can be lost. In part20_fixedwing.py the head-on encounter of Section 6 was rerun with this filter (\(V_g=20\) m/s, \(\phi_{\max}=30^\circ\) so \(\omega_{\max}=16.2^\circ\)/s, \(\ell=20\) m, \(\tilde d_s=90\) m, UAV 2 at 5 m to UAV 1's left so both turn right):

With \(\gamma\ge1\) the requested turn rate exceeded \(\omega_{\max}\) and the look-ahead barrier was crossed; the true distance stayed above 50 m only because of the \(2\ell=40\) m inflation. The lesson: for a vehicle with bounded turn rate, \(\gamma\) and \(d_s\) must be chosen so that the constraint activates outside the turn reaction distance, computed next.

High-speed note. Three quantities scale differently with speed. The latency inflation grows like \(V_g\); the turn reaction distance grows like \(V_g\) at fixed bank but the turn radius grows like \(V_g^2\); and at high speed the structural limit \(n_{z,\max}\) rather than the bank angle sets \(a_{\mathrm{lat}}=g\sqrt{n_{z,\max}^2-1}\) (Part 16). 7.4 Collision cone, feasibility, right-of-way and altitude

  • Collision-cone barrier. For constant velocities a collision occurs iff \(\Delta v\) lies in the cone of half-angle \(\beta=\arcsin(d_s/\|\Delta p\|)\) around \(-\Delta p\). The function \(h_{\mathrm{cc}}=\Delta p^T\Delta v+\|\Delta p\|\|\Delta v\|\cos\beta\) is non-negative outside the cone and has relative degree one in both acceleration and turn-rate inputs because \(\Delta v\) depends on \(\chi\) (Thontepu et al. 2022). It avoids the look-ahead inflation but is non-smooth at \(\Delta v=0\) and is not a barrier for a pair that is already inside the cone.
  • Feasibility. With \(V_{\min}\gt0\) the "stop" solution of Section 6.1 is outside \(U\). Always check the QP for infeasibility and have a fallback (hold the previous safe command, climb, or a priority rule); a soft version adds a slack \(\delta\ge0\) to the barrier row with a large penalty \(\rho\delta^2\) so the QP is always solvable and \(\delta\gt0\) is logged as a safety-margin breach.
  • Deadlock and right-of-way. Symmetric encounters stall any symmetric filter. Give the nominal command a deterministic bias toward the right (the aviation convention) when the pair is nearly head-on, or assign priorities by index so the lower-priority aircraft takes the whole correction (set \(b_{ij}\leftarrow 2b_{ij}\) for it and \(0\) for the other).
  • Altitude is the cheap axis. Vertical separation needs no bank. A barrier \(h^{\mathrm{alt}}_{ij}=(h_i-h_j)^2-d_{s,\mathrm{alt}}^2\) is relative degree one in the climb-rate command. Climbing 15 m at \(\gamma=5^\circ\) takes \(15/\sin5^\circ=172\) m of track at any speed (8.6 s at 20 m/s, 0.86 s at 200 m/s): for high-speed aircraft altitude is the only de-confliction that does not scale badly.

7.5 Velocity obstacles and ORCA, briefly

Velocity obstacles (Fiorini & Shiller 1998) forbid the set of velocities that lead to collision within a time horizon; reciprocal versions (RVO; ORCA, van den Berg et al. 2011) split the avoidance effort between the two agents through a half-plane in velocity space, which is formally very close to the half-split CBF of Section 4. The differences: ORCA is a geometric construction with a finite time horizon and no invariance proof; the CBF is an invariance condition with a tunable approach rate and works unchanged with acceleration inputs through the HOCBF. Both reduce to "one half-plane per neighbour, then a small QP".

7.6 The safety-filter architecture

Toward the CLAW This lesson supplies the safety block of the unified control law. It consumes the nominal acceleration or velocity command \(u_i^{\mathrm{nom}}\) produced by the formation/guidance blocks (Parts 12, 18, 19), the latest neighbour states \((p_j,v_j)\) with their age \(\tau\), and the envelope \([V_{\min},V_{\max}]\), \(\omega_{\max}(V_g)\) from Part 16. It produces the filtered command \(u_i^\ast\) (closed form for one neighbour, a 2–3 variable QP otherwise), which is then mapped to \((V_g^c,\chi^c)\) exactly as in Part 9. Its parameters in the CLAW are \(d_s\) (inflated by \(V_{\mathrm{closing}}\tau\)), \(\gamma\) or \((\alpha_1,\alpha_2)\) scheduled with \(V_g\), the look-ahead \(\ell\), and the altitude barrier distance \(d_{s,\mathrm{alt}}\). It is the only block that is allowed to override every other block.

8. Implementation

The script below reproduces Section 6.1 (closed-form filter for one neighbour, Hildreth's dual ascent for several). It needs only NumPy.

import numpy as np
# --- Part 20: decentralised CBF safety filter, single-integrator UAVs, (north, east) in metres
ds, gamma, V, Ts = 50.0, 0.5, 20.0, 0.05       # safety distance, alpha(h)=gamma*h, speed, sample time

def hildreth(unom, G, w, iters=2000, tol=1e-10):
    """min 0.5||u-unom||^2  s.t.  G u <= w   (dual coordinate ascent, Hildreth 1957).
    u = unom - G^T lam, lam >= 0. Exact for one constraint; converges for several."""
    u = unom.copy()
    if np.all(G @ u <= w + 1e-12): return u, np.zeros(len(w))
    P = G @ G.T; d = w - G @ unom; lam = np.zeros(len(w))
    for _ in range(iters):
        old = lam.copy()
        for i in range(len(w)):
            lam[i] = max(0.0, -(d[i] + P[i] @ lam - P[i, i] * lam[i]) / P[i, i])
        if np.max(np.abs(lam - old)) < tol: break
    return unom - G.T @ lam, lam

def cbf_rows(pi, others):
    """One half-split row per neighbour:  2(pi-pj)^T u >= -gamma/2 * h_ij  ->  G u <= w."""
    G, w = [], []
    for pj in others:
        dp = pi - pj; h = dp @ dp - ds**2
        G.append(-2.0 * dp); w.append(0.5 * gamma * h)
    return np.array(G), np.array(w)

def filt(unom, pi, others):
    G, w = cbf_rows(pi, others)
    if len(others) == 1:                                   # closed form: projection on a half-space
        a, b = -G[0], -w[0]
        lam = max(0.0, b - a @ unom) / (a @ a)
        return unom + lam * a, lam
    return hildreth(unom, G, w)

def nominal(p, goal):                                      # straight to the goal at speed V
    d = goal - p; return V * d / np.linalg.norm(d)

p = [np.array([0.0, 0.0]), np.array([400.0, 5.0])]        # UAV 1 flies north, UAV 2 flies south
goal = [np.array([800.0, 0.0]), np.array([-400.0, 5.0])]
t, dmin, t_act = 0.0, np.inf, None
while t < 25.0:
    unom = [nominal(p[i], goal[i]) for i in range(2)]
    u, lam = zip(*[filt(unom[i], p[i], [p[1 - i]]) for i in range(2)])
    r = np.linalg.norm(p[0] - p[1])
    if lam[0] > 0 and t_act is None:
        t_act = t; print(f"filter active from t={t:.2f}s, r={r:.2f} m, u1_nom={unom[0]}, u1*={np.round(u[0],3)}")
    if abs(t - round(t)) < 1e-9 and 6 <= t <= 13:
        print(f"t={t:4.1f} r={r:7.2f} u1*=({u[0][0]:6.2f},{u[0][1]:6.2f}) |u1*|={np.linalg.norm(u[0]):5.2f} lam={lam[0]:.4f}")
    dmin = min(dmin, r)
    p = [p[i] + Ts * u[i] for i in range(2)]; t += Ts
print(f"minimum distance {dmin:.2f} m (d_s = {ds})")

Expected output: activation at \(t=5.65\) s and \(r=174.07\) m, the table rows of Section 6.1, and minimum distance 54.22 m. For production use replace hildreth by OSQP (osqp package) or quadprog; both solve a 2-variable QP in microseconds.

9. Common Pitfalls

  • Sign of \(a\). \(a_{ij}=2(p_i-p_j)\) points from the neighbour to you. Using \(p_j-p_i\) silently turns the filter into a collision seeker.
  • Forgetting the half. If both UAVs impose the full centralised constraint the pair is over-conservative; if neither halves it and each assumes the other does nothing, the sum is still safe — but if each assumes the other does all the work, it is not.
  • Relative degree. A barrier that depends on position only has no \(u\) in \(\dot h\) for double-integrator or turn-rate inputs; the QP constraint row is \(0\ge b\) and the solver either ignores it or reports infeasibility. Use the HOCBF or the look-ahead point.
  • Sampling. The invariance proof is continuous-time. With sample time \(T_s\) the state can overshoot by up to \(\|u\|T_s\) per step; inflate \(d_s\) by the worst-case step and keep \(\gamma T_s\ll1\) (here \(0.5\times0.05=0.025\)).
  • Stale neighbour data. Not inflating \(d_s\) by \(V_{\mathrm{closing}}\tau\) is the most common field failure: at 60 m/s with 1 s of latency the pair is 120 m closer than the filter thinks.
  • Gain not scheduled with speed. A \(\gamma\) tuned at 20 m/s activates far inside the turn reaction distance at 60 m/s (174 m versus 360 m).
  • Trusting the filter to pick a side. Symmetric geometry gives deadlock or a last-moment flip; add the right-of-way bias in \(u^{\mathrm{nom}}\), not in the barrier.
  • Angle wrap. When mapping \(u^\ast\) to \(\chi^c\) use atan2 and wrap \(\chi^c-\chi\) to \((-\pi,\pi]\) before forming the turn-rate command (Part 15).

10. Exercises

Exercise 1 (derivation). Show that for a general positive-definite weighting \(M\), the filter \(\min\tfrac12(u-u^{\mathrm{nom}})^TM(u-u^{\mathrm{nom}})\) s.t. \(a^Tu\ge b\) has the solution \(u^\ast=u^{\mathrm{nom}}+\max(0,b-a^Tu^{\mathrm{nom}})\,M^{-1}a/(a^TM^{-1}a)\). Why would you weight the along-track direction more heavily than the cross-track direction for an aircraft?
Show solution
KKT: \(M(u-u^{\mathrm{nom}})=\lambda a\) gives \(u=u^{\mathrm{nom}}+\lambda M^{-1}a\); the active constraint \(a^Tu=b\) gives \(\lambda=(b-a^Tu^{\mathrm{nom}})/(a^TM^{-1}a)\), clipped at zero. A large along-track weight makes speed changes "expensive", so the projection prefers a lateral (turning) correction, which is what a fixed-wing aircraft can actually deliver.
Exercise 2 (numeric). Two UAVs head-on at 30 m/s each, \(d_s=40\) m, \(\gamma=1\) s\(^{-1}\). At what range does the filter activate?
Show solution
\(r_{\mathrm{act}}=2V/\gamma+\sqrt{(2V/\gamma)^2+d_s^2}=60+\sqrt{3600+1600}=132\) m (132.1 m).
Exercise 3 (numeric). Two aircraft at 150 m/s head-on exchange states with 0.3 s latency. By how much must \(d_s\) be inflated? And with 0.1 s?

\(V_{\mathrm{closing}}\tau=300\times0.3=90\) m; with 0.1 s, 30 m.

11. Key Takeaways & Formula Sheet

  • Safety = forward invariance of \(\mathcal C=\{h\ge0\}\); Nagumo: \(\dot h\ge0\) on the boundary suffices.
  • CBF condition: \(\sup_u[L_fh+L_ghu]\ge-\alpha(h)\); any Lipschitz \(u\in K_{\mathrm{cbf}}\) keeps \(\mathcal C\) invariant; with \(\alpha(h)=\gamma h\), \(h(t)\ge h(0)e^{-\gamma t}\).
  • CBF-QP: \(u^\ast=\arg\min\tfrac12\|u-u^{\mathrm{nom}}\|^2\) s.t. \(L_fh+L_ghu\ge-\alpha(h)\), \(u\in U\).
  • Pair barrier \(h_{ij}=\|p_i-p_j\|^2-d_s^2\); decentralised half: \(2(p_i-p_j)^Tu_i\ge-\tfrac12\gamma h_{ij}\).
  • Closed form: \(u^\ast=u^{\mathrm{nom}}+\max(0,b-a^Tu^{\mathrm{nom}})\,a/\|a\|^2\).
  • Activation range (head-on): \(r_{\mathrm{act}}=2V/\gamma+\sqrt{4V^2/\gamma^2+d_s^2}\).
  • HOCBF (double integrator): \(2\Delta p^Tu_i\ge-\|\Delta v\|^2-(\alpha_1+\alpha_2)\Delta p^T\Delta v-\tfrac12\alpha_1\alpha_2h\), requires \(\psi_1(0)=2\Delta p^T\Delta v+\alpha_1h\ge0\).
  • Braking barrier: \(h_{\mathrm{br}}=\sqrt{4a_{\max}(\|\Delta p\|-d_s)}+\Delta p^T\Delta v/\|\Delta p\|\).
  • Look-ahead point: \(\dot{\tilde p}=R(\chi)[V_g,\ \ell\omega]^T\), inflate \(\tilde d_s=d_s+2\ell\).
  • Reaction distance \(D_{\mathrm{react}}\approx2V_g\sqrt{d_s/(g\tan\phi_{\max})}\); latency inflation \(d_s\leftarrow d_s+V_{\mathrm{closing}}\tau\) (60 m/s head-on, 1 s: 120 m).
  • Schedule \(\gamma\) with \(V_g\); altitude is the de-confliction axis whose cost does not grow with speed.
