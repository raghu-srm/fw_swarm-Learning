# Reference implementation spec — the Unified Swarm CLAW simulator (`sim/`)

Purpose: a small, readable, pure-NumPy (+ matplotlib for plots) Python package that implements the layered
control law taught in the course, so the reader can run it, read it alongside the lessons, and modify it.
Target: `/home/ragupathi/dev/study/fw_swarm-Learning/sim/` plus `/home/ragupathi/dev/study/fw_swarm-Learning/tests/test_sim.py`.
Python 3.12, NumPy 2.x, SciPy 1.11 (optional), matplotlib 3.10. No other dependencies. Headless plotting (`matplotlib.use("Agg")`).

Notation follows the course brief (`BRIEF.md`, Section 2): NED horizontal position `p = (p_n, p_e)`, course `chi`
clockwise from north, ground speed `Vg`, altitude `h`, `R(psi) = [[cos,-sin],[sin,cos]]`, `J = [[0,-1],[1,0]]`.
Adjacency `A[i,j] > 0` means i transmits to j; listening weights `W = A.T`; `L = diag(W.sum(1)) - W`.

## Layers (per UAV i, computed at the control rate f_ctrl = 20 Hz; comms at f_comm = 10 Hz)

### L0 Reference (virtual structure, generated by the leader/GCS; `reference.py`)
State `xi = (p_c, psi_c, V_c, omega_c, h_c)`. Racetrack: straight legs of length `leg` and 180° coordinated turns with
bank `phi_c`: `omega_c = g*tan(phi_c)/V_c` during turns, 0 on legs. Propagation: `p_c += V_c*[cos psi_c, sin psi_c]*dt`, `psi_c += omega_c*dt`.
Mode switching by distance travelled on the leg / angle turned.

### L1 Distributed reference estimation (`estimator.py`)  — Parts 7, 8, 13
Each UAV keeps `xi_hat_i`. Every control step: propagate with the model above (using its own `V_hat, omega_hat`).
Every comm step, using the latest received neighbour estimates `xi_hat_j` (possibly stale) and, for pinned UAVs (`b_i > 0`), the true `xi`:
  `xi_hat_i -= T_comm * k_xi * ( sum_j W[i,j]*(xi_hat_i - xi_hat_j) + b_i*(xi_hat_i - xi) )`
with angle components differenced through `wrap(a-b)`. Explain in docstrings that this is leader–follower consensus (H = L + B).

### L2 Formation guidance (`formation.py`) — Parts 10, 12, 13
Slot: `p_d_i = p_c_hat + R(psi_c_hat) @ r_i`; slot velocity `v_d_i = V_c_hat*[cos psi_c_hat, sin psi_c_hat] + omega_c_hat * R(psi_c_hat) @ J @ r_i`.
Command: `v_cmd_i = v_d_i - k_p*(p_i - p_d_i) - k_c * sum_j W[i,j] * ((p_i - p_j) - (p_d_i - p_d_j))`,
where `p_j` is the neighbour's last received position dead-reckoned forward with its last received velocity, and `p_d_j` uses UAV i's own `xi_hat_i` and the known `r_j`.
Saturate the correction: `||v_cmd_i - v_d_i|| <= dv_max` (scale down if exceeded).
Altitude: `h_cmd_i = h_c_hat + dh_i` (altitude stacking: `dh_i` from the formation table).

### L3 Safety filter (`safety.py`) — Part 20
Pairwise CBF at the velocity-command level, decentralised split. For each neighbour j within `r_sense` and with `|h_i - h_j| < h_sep`:
  `dp = p_i - p_j`, `h_ij = ||dp||^2 - d_s_eff^2`, `d_s_eff = d_s + V_closing * tau_comm`  (V_closing = max(0, -(v_i - v_j).dp_hat)),
  constraint `2*dp @ v_i >= -0.5*alpha*h_ij`.
Solve `min ||v - v_cmd||^2` s.t. all pair constraints by cyclic projection onto the half-spaces (≤ 20 sweeps, closed form
`v += max(0, b - a@v) * a/(a@a)`), then clip speed to `[V_min, V_max]` (document that this is an approximation of the QP;
for one active constraint it is exact). Return the filtered `v_safe` and a flag telling whether the filter was active.

### L4 Vehicle command mapping (`mapping.py`) — Parts 15, 16
`chi_cmd = atan2(v_e, v_n)`, `V_cmd = clip(||v_safe||, V_min, V_max)`. Nothing else here; rate limiting lives in the vehicle model.

### Vehicle (command-level model; `vehicle.py`) — Parts 15, 16
`chi_dot = clip(b_chi * wrap(chi_cmd - chi), -omega_max, omega_max)`, `omega_max = g*tan(phi_max)/Vg`,
`Vg_dot = clip(b_V * (V_cmd - Vg), -a_max, a_max)`, `h_dot = clip(b_h*(h_cmd - h), -hdot_max, hdot_max)`,
`p_dot = Vg*[cos chi, sin chi]`. Euler integration at `dt = 1/f_ctrl`. Envelope helper: `turn_radius(Vg, phi)`, `omega_max(Vg, phi_max, nz_max)`.

### Comms (`comms.py`) — Parts 6, 23
Every comm step each UAV broadcasts `(t, p, v, h, xi_hat)`. Delivery to each listener j with `A[i,j] > 0` after latency `tau_comm`
(rounded to comm steps) and with independent packet-loss probability `p_loss`. Each UAV keeps the last received packet per neighbour
(timestamped) — used by L1/L2/L3 with dead-reckoning `p_j(t) ≈ p_j(t_rx) + v_j(t_rx)*(t - t_rx)`.

### Graph utilities (`graph.py`) — Parts 1–4, 7
`listening_matrix(A)`, `laplacian_in(A)`, `has_spanning_tree(A)` (BFS from every candidate root using the course convention), `lambda2(A)` for undirected,
`ring_with_leader(N)` and `vee_formation_graph(N)` builders that return `(A, b)` where `b` marks UAVs that hear the reference directly.

## Presets (`presets.py`)
`small`: N=5, V_c=25 m/s, V in [16, 32], phi_max=45°, phi_c=30°, b_chi=1.5, b_V=0.8, b_h=0.5, a_max=3, hdot_max=3, leg=2000 m, vee spacing 60 m along × 40 m across,
dh = [0, +10, -10, +20, -20] m, d_s=30 m, h_sep=8 m, tau_comm=0.1 s, p_loss=0.1, k_xi=1.0, k_p=0.6, k_c=0.3, dv_max=6 m/s, alpha=0.6.
`high`: N=5, V_c=150 m/s, V in [120, 190], phi_max=60°, phi_c=45°, b_chi=0.8, b_V=0.3, a_max=6, leg=12000 m, spacing 400 m × 250 m, d_s=150 m, tau_comm=0.15 s, p_loss=0.1,
k_xi=1.0, k_p=0.4, k_c=0.2, dv_max=25 m/s, alpha=0.5. Check the discrete-time rule `dt*(k_p + k_c*lambda_N) < 2` and print it at start.
Start: UAVs scattered ±300 m (small) / ±2000 m (high) around the first slots with random courses; `xi_hat_i` initialised to the true reference + noise.

## Runner (`run.py`)
`python3 -m sim.run --preset small --N 5 --duration 400 --loss 0.1 --latency 0.1 [--no-cbf] [--no-feedforward] [--seed 1] [--out out_dir]`
Logs per step: positions, slot errors, min pairwise distance, speed/turn-rate saturation flags, estimator error (`||p_c_hat - p_c||`, `wrap(psi_c_hat - psi_c)`).
Prints a summary table (RMS slot error after transient, max/min, min distance, % steps saturated, % steps CBF active) and saves
`trajectories.png`, `slot_errors.png`, `min_distance.png`, `speeds_courses.png` to `--out` (default `sim_out/`).
`--no-feedforward` drops the `v_d_i` term (to demonstrate the lag discussed in Part 12).

## Tests (`tests/test_sim.py`, runnable with `python3 -m pytest` or plain `python3 tests/test_sim.py`)
1. `laplacian_in` rows sum to zero; `has_spanning_tree` true for a ring-with-leader, false for a disconnected graph.
2. Slot velocity formula matches a finite-difference derivative of the slot position (tolerance 1e-3).
3. Safety filter: two UAVs head-on, filtered command satisfies the pair constraint; with no conflict the command is unchanged.
4. Vehicle model respects `omega_max` and speed bounds.
5. Full small preset, 120 s, seed 1: no pair closer than `d_s`, RMS slot error after 60 s below 15 m, run time under 30 s.
