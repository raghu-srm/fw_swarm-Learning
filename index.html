Fixed-Wing Swarm Learning

A self-contained, mathematics-first course on distributed control of fixed-wing UAV swarms — from graphs and consensus, through formation, guidance and safety, to a unified swarm control law (CLAW) that you can implement on PX4 + ROS 2, including high-speed aircraft.

What this course is for

The end goal is a single engineering capability: design, analyse and implement a control law that makes a group of fixed-wing aircraft behave as one coordinated system — agreeing on references, holding and manoeuvring formations, following paths cooperatively, staying safe, dividing tasks, and doing all of this with the speed envelope, turn-rate limits and communication latency of real aircraft.

Who it is forEngineers with calculus, linear algebra and basic control, new to multi-agent systems.
How it teachesEvery part derives the mathematics, verifies it numerically, and ends with a "Toward the CLAW" box that says exactly which block of the final law it supplies.
What you buildBy Part 24 you assemble a layered CLAW (estimation → formation → safety → vehicle command) and run it in the included Python simulator.

How to study

  1. Read with pen and paper. Re-derive every boxed equation yourself before moving on.
  2. Run the code. Every part ends with a NumPy snippet that reproduces its worked example. Change the numbers; watch what breaks.
  3. Do the exercises. Solutions are hidden behind "Show solution"; attempt first.
  4. Keep the pipeline picture. After each part, say in one sentence which CLAW block it supplies (the "Toward the CLAW" box checks you).
  5. Finish with the simulator. The sim/ package implements the capstone law; read it next to Part 24 and modify it.

Conventions used throughout

Adjacency convention. \(a_{ij}>0\) means UAV \(i\) transmits to UAV \(j\). For directed graphs the controller of UAV \(i\) uses the listening weights \(w_{ij}=a_{ji}\) (Part 7). Most textbooks define \(A\) the other way round; check before copying a formula.
FramesNED inertial frame; heading \(\psi\) and course \(\chi\) clockwise from north; altitude \(h=-p_d\).
Speeds\(V_a\) airspeed, \(V_g\) ground speed (always subscripted). \(V(x)\) with an argument is a Lyapunov function.
Turns\(\dot\chi = g\tan\phi/V_g\), \(R = V_g^2/(g\tan\phi)\), load factor \(n_z=1/\cos\phi\).
Stacked vectors\(x=\mathrm{col}(x_1,\dots,x_N)\), \(\dot x=-(L\otimes I_n)x\).

Reference simulator

The repository ships a pure-NumPy implementation of the capstone CLAW (sim/) with two presets — a 25 m/s small UAV swarm and a 150 m/s high-speed swarm — plus communication latency and packet loss. See sim/README.md.

python3 tests/test_sim.py
python3 -m sim.run --preset small --duration 400 --out sim_out_small
python3 -m sim.run --preset high  --duration 600 --out sim_out_high
python3 -m sim.run --preset small --no-feedforward   # see the lag discussed in Part 12
python3 -m sim.run --preset small --no-cbf           # see why the safety filter exists
