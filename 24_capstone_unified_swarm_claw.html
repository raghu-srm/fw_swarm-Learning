1. What "Unified Swarm Control" Means

Twenty-three parts ago we started with the sentence "a distributed controller needs to know which other UAVs it can communicate with". We can now state precisely what a swarm control law is: a function, run independently on every aircraft, that maps its own state, the last packets heard from its neighbours and a shared mission reference to commands its autopilot can fly.

\[ \boxed{\;u_i \;=\; \mathrm{CLAW}\big(x_i,\;\{\,\text{packets}_j : j\in\mathcal N_i^{\mathrm{in}}\},\;\hat\xi_i,\;\text{mission}\big)\;} \]

Unified means one such law covers all the behaviours we studied — formation flight, formation manoeuvring, rendezvous, loiter patterns, re-tasking, collision avoidance — by changing only the reference and the formation slots, never the controller. Behaviours are data; the control law is fixed. This is what makes the swarm testable: one code path, one stability argument, one set of gains per aircraft class.

InputEverything in Parts 1–23. If a symbol below is unfamiliar, the layer headings say which part defines it.
OutputA complete, implementable CLAW with gains for two aircraft classes, a convergence/safety argument, and a simulation you can run.
Companion codesim/ in the repository implements every equation of this part, module for module.

The law is layered (Figure 1). Each layer is a block we already derived: consensus (Parts 5–8) estimates the reference, formation control (Parts 9–13) turns it into a velocity command, a control barrier function (Part 20) filters that command for safety, and the vehicle layer (Parts 15–16) turns the result into course, speed and altitude commands for the autopilot (Part 23). Task allocation (Part 22) and path primitives (Parts 17–19) live above, in the mission layer.

4. Signals, Packets and the Communication Graph

4.1 Own state

From the autopilot (Part 15, Part 23): horizontal NED position \(p_i=(p_{n,i},p_{e,i})\), ground speed \(V_{g,i}\), course \(\chi_i\), altitude \(h_i\), airspeed \(V_{a,i}\) and a timestamp. The inertial velocity is \(v_i=V_{g,i}(\cos\chi_i,\sin\chi_i)\).

4.2 The packet

Every \(T_{\mathrm{comm}}=100\) ms each UAV broadcasts one packet. Keep it small; everything else can be derived.

FieldSymbolWhy
timestamp\(t_{\mathrm{tx}}\)dead-reckoning and staleness checks (Part 6)
position, velocity, altitude\(p_j, v_j, h_j\)formation coupling (L2) and safety (L3)
reference estimate\(\hat\xi_j\)consensus on the reference (L1)
UAV id, slot id, health—fallbacks (Section 14)

4.3 The graph

The adjacency matrix \(A\) uses the course convention \(a_{ij}>0\iff i\to j\) (Part 2). The controller of UAV \(i\) uses the listening weights \(w_{ij}=a_{ji}\), i.e. \(W=A^T\), and the in-degree Laplacian \(L=D_{\mathrm{in}}-W\) (Part 7). UAVs that receive the reference directly (from the GCS or by being the lead aircraft) have pinning gain \(b_i=1\); the rest \(b_i=0\) (Part 8). The two conditions every mission plan must satisfy:

\[ \text{(C1) the augmented graph (reference as root) has a directed spanning tree,}\qquad \text{(C2) } H=L+B \text{ has } \operatorname{Re}\lambda_{\min}(H)\gt0 . \]

For an undirected graph (C1) is "connected and at least one pinned UAV", and (C2) follows (Part 8, Theorem). For the 5-aircraft undirected ring used in the simulator the Laplacian eigenvalues are

\[ \lambda(L)=\{0,\;1.382,\;1.382,\;3.618,\;3.618\}, \]

and pinning only UAV 1 gives \(\lambda_{\min}(H)=0.139\), pinning UAVs 1 and 2 gives \(0.268\), pinning 1 and 3 gives \(0.325\). The slowest estimator mode is set by this number (Section 6), so which aircraft hear the reference is a design choice, not an accident.

4.4 Dead-reckoning stale packets

At control time \(t\) a neighbour's last packet is \(\tau_j=t-t_{\mathrm{tx},j}\) old (latency plus lost packets). Every use of \(p_j\) below means the propagated value

\[ \tilde p_j(t)=p_j(t_{\mathrm{tx},j})+v_j(t_{\mathrm{tx},j})\,\tau_j , \]

which is exact for straight flight and has error \(\tfrac12 V_{g,j}\,\omega_j\,\tau_j^2\) in a turn (for \(\tau_j=0.3\) s at 150 m/s and 6.5°/s this is 0.8 m — negligible against \(d_s\)). If \(\tau_j\) exceeds \(T_{\mathrm{stale}}\) (say 1 s), drop \(j\) from \(\mathcal N_i^{\mathrm{in}}\) for L1/L2 but keep it in L3 with an inflated \(d_s\) (Section 8).

5. L0 — Mission & Reference

The mission layer produces two things: a reference (the virtual structure of Part 13) and a slot assignment.

5.1 The reference \(\xi\)

\[ \xi=(p_c,\psi_c,V_c,\omega_c,h_c),\qquad \dot p_c=V_c\begin{bmatrix}\cos\psi_c\\ \sin\psi_c\end{bmatrix},\quad \dot\psi_c=\omega_c,\quad \omega_c=\begin{cases}0 &\text{on a leg}\\ \pm\,g\tan\phi_c/V_c &\text{in a turn}\end{cases} \]

A racetrack is legs of length \(\ell\) joined by 180° coordinated turns of bank \(\phi_c\). Any flyable path works: Dubins segments (Part 17), an orbit (Part 18), or a path-parameterised reference for time coordination (Part 19). The only requirement is that every slot, not just the centre, stays inside the envelope (Section 12, check D1).

5.2 Slots

Slots \(r_i\) are fixed vectors in the formation frame (Part 10); altitude offsets \(\Delta h_i\) stack the aircraft vertically so that L3 can ignore pairs that are vertically separated. The simulator's vee for five aircraft, with along-track spacing \(s_x\) and cross-track spacing \(s_y\):

\[ r_1=(0,0),\ r_2=(-s_x,\,s_y),\ r_3=(-s_x,\,-s_y),\ r_4=(-2s_x,\,2s_y),\ r_5=(-2s_x,\,-2s_y),\qquad \Delta h=(0,+10,-10,+20,-20)\ \mathrm{m}. \]

Which aircraft takes which slot is an assignment problem solved with the Hungarian method or CBBA (Part 22) whenever the formation is created or an aircraft is lost; the cost is the Dubins length (Part 17) from the aircraft's pose to the slot, divided by speed.

6. L1 — Distributed Reference Estimation

Only pinned aircraft receive \(\xi\). Everyone else must estimate it, and all estimates must agree, otherwise the slots computed by different aircraft would be inconsistent and the formation would fight itself. This is exactly leader–follower consensus with a dynamic leader (Part 8) applied to the virtual-structure state (Part 13).

\[ \boxed{\; \begin{aligned} \text{propagate (every } T_s\text{):}\quad & \hat p_{c,i} \mathrel{+}= \hat V_{c,i}\begin{bmatrix}\cos\hat\psi_{c,i}\\ \sin\hat\psi_{c,i}\end{bmatrix}T_s,\qquad \hat\psi_{c,i}\mathrel{+}=\hat\omega_{c,i}T_s,\\ \text{correct (every } T_{\mathrm{comm}}\text{):}\quad & \hat\xi_i \mathrel{-}= T_{\mathrm{comm}}\,k_\xi\Big[\sum_{j\in\mathcal N_i^{\mathrm{in}}} w_{ij}\,\big(\hat\xi_i\ominus\hat\xi_j\big)+b_i\big(\hat\xi_i\ominus\xi\big)\Big] \end{aligned}\;} \]

where \(\ominus\) is ordinary subtraction except for the angle component \(\hat\psi_c\), which is differenced through \(\operatorname{wrap}(\cdot)\in(-\pi,\pi]\) (Part 15).

6.1 Error dynamics

Let \(\eta_i=\hat\xi_i-\xi\). Because every copy propagates with the same model, the model terms cancel to first order and in continuous time

\[ \dot\eta=-k_\xi\,(H\otimes I)\,\eta+\varepsilon(t),\qquad H=L+B, \]

where \(\varepsilon\) collects the model mismatch (the reference switching between leg and turn, which the followers learn only through consensus) and the linearisation error of the angle. By Part 8, \(H\) is positive definite under (C1), so

\[ \|\eta(t)\|\le e^{-k_\xi\lambda_{\min}(H)\,t}\|\eta(0)\|+\frac{\sup\|\varepsilon\|}{k_\xi\lambda_{\min}(H)} . \]
Interpretation: the estimate converges exponentially at rate \(k_\xi\lambda_{\min}(H)\), and a switching reference leaves a residual error inversely proportional to that rate. With \(k_\xi=1\) and two pinned aircraft on the ring, the rate is \(0.268\ \mathrm{s^{-1}}\): a turn entry is "learned" by the far side of the formation in about \(3/0.268\approx 11\) s. At 150 m/s that is 1.7 km of flight — which is why the reference should announce turns ahead of time (Section 13) rather than switch abruptly.

6.2 Discrete-time check

The correction is applied at \(T_{\mathrm{comm}}=0.1\) s. By Part 6 the Euler step is stable if \(T_{\mathrm{comm}}\,k_\xi\,\lambda_{\max}(H)\lt2\); for the pinned ring \(\lambda_{\max}(H)=4.41\), so \(k_\xi\lt4.5\). We use \(k_\xi=1\), far from the limit, which also keeps the estimator insensitive to lost packets (Part 6, switching-topology argument).

7. L2 — Formation Guidance

With a local reference estimate each aircraft can compute its own slot and its slot's velocity (Part 13):

\[ p_i^d=\hat p_{c,i}+R(\hat\psi_{c,i})\,r_i,\qquad v_i^d=\hat V_{c,i}\begin{bmatrix}\cos\hat\psi_{c,i}\\ \sin\hat\psi_{c,i}\end{bmatrix}+\hat\omega_{c,i}\,R(\hat\psi_{c,i})\,J\,r_i , \]

and the velocity command combines slot tracking (leader-follower, Part 8) with relative-formation coupling (displacement-based formation control, Part 12):

\[ \boxed{\; v_i^{\mathrm{cmd}} = v_i^d \;-\; k_p\,(p_i-p_i^d)\;-\;k_c\sum_{j\in\mathcal N_i^{\mathrm{in}}} w_{ij}\Big[(p_i-\tilde p_j)-(p_i^d-p_j^d)\Big] \;} \]

Here \(p_j^d=\hat p_{c,i}+R(\hat\psi_{c,i})r_j\) is UAV \(i\)'s idea of where \(j\) should be (so the coupling term needs only \(r_j\), which is mission data, and \(\tilde p_j\), which is in the packet).

7.1 Why both terms

  • The \(k_p\) term alone is \(N\) independent trackers: if one aircraft lags (gust, saturation), its neighbours do not react, and the relative geometry — which is what matters for safety and for sensors — is lost until the laggard catches up.
  • The \(k_c\) term alone is displacement-based formation control (Part 12): it preserves shape but fixes position only up to a translation, which drifts under disturbances.
  • Together, the error \(e_i=p_i-p_i^d\) obeys (perfect estimates, perfect vehicle tracking) \[ \dot e=-\big[(k_pI_N+k_cL)\otimes I_2\big]e , \] whose modes decay at rates \(k_p+k_c\lambda_k\), \(k=1,\dots,N\). The slowest, \(k_p\), is the whole-formation translation; the fastest, \(k_p+k_c\lambda_N\), is the highest-frequency shape mode. The \(k_c\) term makes the shape converge faster than the position, which is the behaviour we want.

7.2 Saturation

The correction \(\delta v_i=v_i^{\mathrm{cmd}}-v_i^d\) is scaled so that \(\|\delta v_i\|\le\Delta v_{\max}\). This keeps the speed command inside \([V_{\min},V_{\max}]\) whenever the slot velocity itself is (check D1) and turns the exponential convergence into a linear approach at \(\Delta v_{\max}\) followed by exponential convergence — the same structure as the vector-field guidance of Part 18.

7.3 The feedforward term is not optional

Dropping \(v_i^d\) leaves a pure tracker, which lags a moving slot by \(\|v_i^d\|/k_p\) (Part 12): 41.7 m at 25 m/s with \(k_p=0.6\), 375 m at 150 m/s with \(k_p=0.4\). The simulator's --no-feedforward flag shows this (Section 15).

7.4 Altitude

\[ h_i^{\mathrm{cmd}}=\hat h_{c,i}+\Delta h_i . \]

Altitude is handled by the autopilot's longitudinal loop (TECS in PX4, Part 23); the CLAW only supplies the stacked target.

8. L3 — Safety Filter

The formation command is nominal. Before it reaches the vehicle, a control barrier function (Part 20) enforces separation against every neighbour \(j\) within sensing range whose altitude is within \(h_{\mathrm{sep}}\) of ours:

\[ h_{ij}=\|p_i-\tilde p_j\|^2-d_{s,\mathrm{eff}}^2,\qquad d_{s,\mathrm{eff}}=d_s+V_{\mathrm{closing}}\,\tau_{\mathrm{comm}},\qquad V_{\mathrm{closing}}=\max\big(0,\,-(v_i-\tilde v_j)\cdot\widehat{(p_i-\tilde p_j)}\big). \]

At the velocity-command level the kinematics are a single integrator, so the decentralised half-split constraint of Part 20 applies directly:

\[ \boxed{\;2\,(p_i-\tilde p_j)^T v_i \;\ge\; -\tfrac12\,\alpha\,h_{ij}\qquad\text{for every active pair } (i,j)\;} \]

and the filtered command is the projection of \(v_i^{\mathrm{cmd}}\) onto the intersection of these half-spaces, then clipped to the speed envelope:

\[ v_i^{\mathrm{safe}}=\arg\min_{v}\|v-v_i^{\mathrm{cmd}}\|^2\ \text{ s.t. all pair constraints},\qquad \text{one constraint: } v=v^{\mathrm{cmd}}+\max\!\big(0,\;b-a^Tv^{\mathrm{cmd}}\big)\frac{a}{\|a\|^2}, \]

with \(a=2(p_i-\tilde p_j)\), \(b=-\tfrac12\alpha h_{ij}\). The simulator solves the multi-constraint case by cyclic projection (a few sweeps), which is exact for one active constraint and a good approximation otherwise; a production implementation uses a small QP solver (Part 20, Part 21).

Latency inflation numbers. Head-on closing at twice the cruise speed with the comm latency: \(2\times25\times0.1=5\) m for the small swarm, \(2\times150\times0.15=45\) m for the high-speed swarm. The inflation is added on top of \(d_s\) (30 m and 150 m respectively), which already accounts for wake and navigation error.

The filter is the last block before the vehicle on purpose: whatever the formation, flocking or MPC layer asks for, separation is enforced here with a guarantee (Section 11). Relative-degree issues of the real aircraft (turn rate, not velocity, is the input) are absorbed by the course-loop bandwidth margin discussed in Section 12.

9. L4 — Vehicle Command Mapping

\[ \boxed{\;\chi_i^c=\operatorname{atan2}\big(v_{e}^{\mathrm{safe}},\,v_{n}^{\mathrm{safe}}\big),\qquad V_{g,i}^c=\operatorname{clip}\big(\|v_i^{\mathrm{safe}}\|,\,V_{\min},\,V_{\max}\big),\qquad h_i^c=h_i^{\mathrm{cmd}}\;} \]

With wind, convert the ground-speed command to an airspeed command through the wind triangle (Part 15) and command course, not heading, so that the autopilot crabs automatically (Part 18). The autopilot's course loop is modelled as the first-order, rate-limited response of Part 15:

\[ \dot\chi_i=\operatorname{clip}\big(b_\chi\operatorname{wrap}(\chi_i^c-\chi_i),\,\pm\omega_{\max}\big),\qquad \omega_{\max}=\frac{g\tan\phi_{\max}}{V_{g,i}},\qquad \dot V_{g,i}=\operatorname{clip}\big(b_V(V_{g,i}^c-V_{g,i}),\,\pm a_{\max}\big). \]

On PX4 this maps to a lateral setpoint (course or lateral acceleration \(a_{\mathrm{lat}}=V_g\dot\chi\)) plus airspeed and altitude setpoints, or to attitude setpoints with \(\phi^c=\arctan(V_g\dot\chi^c/g)\) (Part 23).

10. The CLAW on One Page

Unified swarm CLAW — per UAV \(i\), every \(T_s\)
  1. Ingest. Own state \((p_i,v_i,h_i)\); for each in-neighbour \(j\) the last packet, dead-reckoned: \(\tilde p_j=p_j+v_j\tau_j\).
  2. L1 Estimate. Propagate \(\hat\xi_i\) with the virtual-structure model; at comm ticks correct with \(\hat\xi_i\mathrel{-}=T_{\mathrm{comm}}k_\xi\big[\sum_j w_{ij}(\hat\xi_i\ominus\hat\xi_j)+b_i(\hat\xi_i\ominus\xi)\big]\).
  3. L2 Guide. \(p_i^d=\hat p_c+R(\hat\psi_c)r_i\), \(v_i^d=\hat V_c\hat t(\hat\psi_c)+\hat\omega_cR(\hat\psi_c)Jr_i\); \(v_i^{\mathrm{cmd}}=v_i^d-k_p(p_i-p_i^d)-k_c\sum_jw_{ij}[(p_i-\tilde p_j)-(p_i^d-p_j^d)]\), correction saturated at \(\Delta v_{\max}\); \(h_i^{\mathrm{cmd}}=\hat h_c+\Delta h_i\).
  4. L3 Protect. For each nearby, co-altitude \(j\): enforce \(2(p_i-\tilde p_j)^Tv\ge-\tfrac12\alpha(\|p_i-\tilde p_j\|^2-d_{s,\mathrm{eff}}^2)\) by projection → \(v_i^{\mathrm{safe}}\).
  5. L4 Command. \(\chi_i^c=\operatorname{atan2}(v_e,v_n)\), \(V_{g,i}^c=\operatorname{clip}(\|v_i^{\mathrm{safe}}\|)\), \(h_i^c\) → autopilot.
  6. Broadcast \((t,p_i,v_i,h_i,\hat\xi_i)\) every \(T_{\mathrm{comm}}\).
Parameters: graph \(W,B\); slots \(r_i,\Delta h_i\); gains \(k_\xi,k_p,k_c,\alpha\); limits \(\Delta v_{\max},V_{\min},V_{\max},\phi_{\max},d_s,h_{\mathrm{sep}}\); timing \(T_s,T_{\mathrm{comm}},T_{\mathrm{stale}}\).

Everything else in this part — proofs, gain selection, fallbacks — is about choosing those parameters and knowing what the law guarantees.

11. Stability and Safety Argument

The layers form a cascade: L1 does not depend on L2–L4; L2 depends on L1's output; L3 modifies L2's output; the vehicle tracks L4's output with lag. Cascades of exponentially stable systems driven by bounded inputs are input-to-state stable (Appendix A1), which gives the following.

Proposition (convergence of the CLAW). Assume (A1) the augmented communication graph has a directed spanning tree rooted at the reference, so \(H=L+B\) satisfies \(\operatorname{Re}\lambda_{\min}(H)=:\mu\gt0\) (Part 8); (A2) the reference is flyable by every slot: \(V_{\min}\le\|v_i^d\|\le V_{\max}\) and \(\|\dot v_i^d\|/\|v_i^d\|\le\omega_{\max}\) (Part 10, Part 16); (A3) the vehicle tracks a velocity command with first-order lag \(b\) and \(k_p+k_c\lambda_{\max}(L)\le b/2\) (time-scale separation, Part 16); (A4) packet staleness is bounded by \(T_{\mathrm{stale}}\) and the union graph over any window of length \(T_{\mathrm{stale}}\) satisfies (A1) (Part 6); (A5) the safety filter is inactive (no pair closer than the inflated \(d_s\)). Then the estimator error and the slot errors converge exponentially to a ball whose radius is proportional to the reference's model mismatch and the staleness bound, with rates \(k_\xi\mu\) for L1 and \(k_p\) (slowest) for L2.
Proof sketch. L1: Section 6.1 and Part 8. L2 with exact estimates and ideal vehicle: \(\dot e=-[(k_pI+k_cL)\otimes I_2]e\), eigenvalues \(k_p+k_c\lambda_k\gt0\) under (A1) (for directed \(L\) the real parts are positive, Part 7). Estimator error enters L2 as a bounded additive input through \(p_i^d,v_i^d\) (Lipschitz in \(\hat\xi_i\)); vehicle lag is a first-order filter in the loop, stable under the gain ratio of (A3) (Part 16); staleness and loss are a switching perturbation handled by the common Lyapunov function \(\|e\|^2\) under (A4) (Part 6). ISS of each stage and the cascade structure give the result.
Proposition (safety). If at \(t=0\) every pair satisfies \(h_{ij}\ge0\) and at every step the projection in L3 is feasible (each pair's half-space intersects the speed envelope), then \(h_{ij}(t)\ge0\) for all \(t\) at the command level; the real aircraft additionally violates by at most \(V_g\,\Delta\chi/\!b_\chi\) during the course-loop transient, which the inflation of \(d_s\) is sized to cover.
Proof sketch. Part 20: the pair constraint is \(\dot h_{ij}\ge-\alpha h_{ij}\) (each aircraft contributes half), so \(h_{ij}(t)\ge h_{ij}(0)e^{-\alpha t}\ge0\) (Nagumo / comparison lemma). Feasibility is the only assumption; Section 14 says what to do when it fails.
What is not proved. Convergence while the filter is active (the filter can create temporary deadlocks, Part 20), convergence when (A2) fails (an infeasible reference produces saturation — see check D1), and anything about the autopilot's inner loops, which we take as given (Part 23).

D1 — Formation feasibility in turns (Part 10)

All slots share \(\omega_c\); the slot at lateral offset \(y\) flies at \(V_c(1+y/R_c)\). The outermost slot of the vee sits at \(y=\pm2s_y\). Feasible offsets are \(-R_c(1-V_{\min}/V_c)\le y\le R_c(V_{\max}/V_c-1)\), which gives a maximum bank for the reference:

\[ R_c\ \ge\ \max\!\Big(\frac{2s_y}{V_{\max}/V_c-1},\ \frac{2s_y}{1-V_{\min}/V_c}\Big)\quad\Longrightarrow\quad \tan\phi_c\le\frac{V_c^2}{g\,R_c}. \]

Lesson. Formation width, reference bank and speed envelope are one coupled design. A 25 m/s swarm with an 80 m-wide vee cannot turn at 30°; it turns at 12° (radius 300 m) or collapses into trail before turning (Section 13). This is the single most common error in fixed-wing formation design, and the law cannot fix it — only the reference can.

D2 — Time-scale separation (Part 16)

The fastest L2 mode must be slower than the course loop that has to realise it: \(k_p+k_c\lambda_{\max}(L)\le b_\chi/2\) (factor 2–3 in practice).

\[ \text{Small: } b_\chi/2=0.75\ \mathrm{s^{-1}},\qquad \text{High: } b_\chi/2=0.4\ \mathrm{s^{-1}}. \]

With \(\lambda_{\max}(L)=3.618\) on the 5-ring, the original spec values \((k_p,k_c)=(0.6,0.3)\) give \(1.69\ \mathrm{s^{-1}}\) — above \(b_\chi\) itself and therefore oscillation-prone. Section 15 lists the values that passed in simulation.

D3 — Discrete-time step (Part 6)

\[ T_s\,(k_p+k_c\lambda_{\max}(L))\lt 0.5\ (\ll2),\qquad T_{\mathrm{comm}}\,k_\xi\,\lambda_{\max}(H)\lt0.5 . \]

At 20 Hz both are satisfied with wide margin for any gains that pass D2; D3 only bites if the control rate is reduced to a few hertz.

D4 — Estimator speed vs. reference switching (Section 6)

The far side of the formation learns a reference change at rate \(k_\xi\lambda_{\min}(H)\). Choose the pinned set to make \(\lambda_{\min}(H)\) large (pin 1 and 3 on the ring: 0.325 instead of 0.139) and announce turns \(\ge3/(k_\xi\lambda_{\min}(H))\) seconds ahead, or broadcast the future reference (turn start time and bank) so that every copy switches simultaneously.

D5 — Safety margins (Part 20)

\[ d_{s,\mathrm{eff}}=d_s+2V_c\tau_{\mathrm{comm}}+\text{nav error}+\text{course-loop transient }V_c\,\Delta\chi_{\max}/b_\chi . \]

Small: \(30+5+5+25\cdot0.5/1.5\approx48\) m worst case; high: \(150+45+10+150\cdot0.3/0.8\approx261\) m. Slot spacing must exceed \(d_{s,\mathrm{eff}}\) with margin, otherwise the filter is permanently active and D1–D4 no longer describe the closed loop; altitude stacking (\(h_{\mathrm{sep}}\)) removes most pairs from the filter entirely.

13. High-Speed Adaptations

Nothing in the CLAW's structure changes with speed; six parameters and modes do. Each is a consequence of a scaling law from Part 16.

Effect of speedScalingAdaptation in the CLAW
Turn radius grows\(R\propto V_g^2\)Formation width must stay a small fraction of \(R_c\) (check D1); reference bank limited by the outermost slot, not by the lead aircraft.
Turn rate falls\(\omega_{\max}\propto1/V_g\)Lower \(k_p,k_c\) (check D2); larger \(\Delta v_{\max}\) in absolute terms but smaller as a fraction of \(V_c\).
Latency covers more ground\(V_g\tau\)\(d_s\) inflation (D5); dead-reckoning mandatory; higher comm rate if the radio allows.
Speed changes are slow\(P_s=(T-D)V/W\) smallPrefer along-path spacing and trail formations in turns (Part 19), where speed, not lateral position, is the control; avoid wide vees at high \(V\).
Roll takes time\(\phi_{\max}/p_{\max}\) ≈ 1 sLower \(b_\chi\) in the design model; announce turns early (D4) so the estimator, not the tracker, absorbs the transient.
Structural limit\(n_{z,\max}\)\(\omega_{\max}=\min\big(g\tan\phi_{\max},\,g\sqrt{n_{z,\max}^2-1}\big)/V_g\) in L4's vehicle model; above corner speed the bank limit is the binding one.

Mode switching: vee on legs, trail in turns

For high-speed swarms the cleanest solution to D1 is a time-varying slot table \(r_i(t)\) (Part 10): a few seconds before a turn the reference morphs the vee into a trail (\(r_i\to(-i\,s_x,0)\)); after the turn it morphs back. Because the slots are part of \(\xi\)-synchronised mission data, every aircraft morphs in step, and the CLAW's equations do not change — \(v_i^d\) simply acquires the \(\dot r_i\) term, \(v_i^d\mathrel{+}=R(\hat\psi_c)\dot r_i\). In a trail every slot has \(y=0\), so the turn is feasible at any bank the lead can fly.

Acceptance test plan

  1. SITL, 1 aircraft: L4 only; verify course-loop bandwidth \(b_\chi\) and speed-loop \(b_V\) from step responses (they are design inputs to D2).
  2. SITL, 5 aircraft, no loss: assembly from scattered starts; metrics as in Section 15; compare with sim/.

17. Extending the CLAW

  • Wind. Estimate \(w\) in the autopilot; L4 converts \(V_g^c\) to \(V_a^c\) by the wind triangle; D1 becomes a ground-speed check with \(V_a\) limits mapped through the wind (Part 15).
  • 3-D formations. Replace \(R(\psi_c)\) by a 3-D rotation and add a flight-path-angle command; altitude stacking already gives most of the benefit.
  • GPS-denied / no common heading. Replace the L2 coupling term by the distance-based gradient law of Part 12 over a rigid graph (Part 11); only body-frame relative positions are needed.
  • Predictive guidance. Replace L2 by the distributed MPC of Part 21 using the same slots and the same L3 filter; the cascade argument is unchanged.
  • Flocking mode. For loose transit, replace L2 by Olfati-Saber's Algorithm 2 (Part 14) with \(\hat\xi_i\) as the \(\gamma\)-agent; L1, L3, L4 unchanged.
  • Time-critical missions. Use the path-parameter consensus of Part 19 as the L1 state (\(\zeta\) instead of \(p_c\)) and along-path slots; simultaneous arrival becomes a consensus target.
  • Sensing instead of comms. If neighbours are sensed rather than heard, \(\tilde p_j\) comes from the sensor and L1 needs an observer of \(\hat\xi_j\) from relative motion — the structure survives, the guarantees weaken (Part 6 noise bounds).

18. Design Exercises

Exercise 1 (D1). A 60 m/s swarm with \(V\in[45,80]\) m/s flies a vee with \(s_y=100\) m (outer slots at ±200 m). What is the largest reference bank, and which slot limits it?
Show solution
Outside: \(R_c\ge200/(80/60-1)=600\) m; inside: \(R_c\ge200/(1-45/60)=800\) m. The inner slot limits. \(\tan\phi_c\le60^2/(9.81\cdot800)=0.459\), \(\phi_c\le24.7^\circ\).
Exercise 2 (D2). The same swarm uses a 6-aircraft undirected ring (\(\lambda_{\max}=4\)) and a course loop with \(b_\chi=1.2\ \mathrm{s^{-1}}\). Choose \(k_p,k_c\) so that the shape modes are three times faster than the translation mode and D2 holds with a factor 2.
Show solution
Need \(k_p+4k_c\le0.6\) and \(k_p+k_c\lambda_2=3k_p\) with \(\lambda_2=1\) (6-ring: \(2-2\cos(\pi/3)=1\)) ⇒ \(k_c=2k_p\) ⇒ \(9k_p\le0.6\) ⇒ \(k_p=0.067,\ k_c=0.133\). Translation time constant 15 s — slow, which is the price of a ring with a slow course loop; a denser graph (larger \(\lambda_2/\lambda_{\max}\)) would help more than gain tuning.
Exercise 3 (L1). Show that if every \(\hat\xi_i\) is initialised to the same wrong value and the reference is constant, the estimator error decays as \(e^{-k_\xi\lambda_{\min}(H)t}\) only in the pinned direction and explain why pinning more aircraft helps.
Show solution
With equal initial errors \(\eta(0)=\eta_0\mathbf 1\), \(\dot\eta=-k_\xi H\eta\) and \(H\mathbf 1=B\mathbf 1=b\) (since \(L\mathbf 1=0\)): the error leaves the consensus direction only through the pinned entries. \(\mathbf 1\) is not an eigenvector of \(H\), so the decay mixes modes, but the component along the slowest eigenvector of \(H\) decays at \(k_\xi\lambda_{\min}(H)\). More pinned aircraft increase \(\lambda_{\min}(H)\) (Part 8: 0.139 → 0.268 → 0.325 on the 5-ring).
Exercise 4 (D5). Two aircraft on adjacent vee slots at 150 m/s are 250 m apart laterally and 400 m longitudinally. With \(d_s=150\) m and a 300 ms worst-case staleness, is the pair ever "active" in L3 during a correctly executed 40° turn? Use the slot-speed result from D1.
Show solution
Slot separation is \(\sqrt{250^2+400^2}=472\) m and does not change in a coordinated turn (rigid rotation). \(d_{s,\mathrm{eff}}\le150+2\cdot150\cdot0.3=240\) m \(\lt472\) m, so \(h_{ij}\gt0\) with margin; the pair is inactive unless a slot error exceeds about 230 m. Altitude stacking (\(\Delta h=10\) m, \(h_{\mathrm{sep}}=8\) m) removes the pair from the filter regardless.
Exercise 5 (code). In sim/, change the graph to a directed chain \(1\to2\to3\to4\to5\) with only UAV 1 pinned. Predict from Part 7 what happens, then run the small preset and compare the estimator error of UAV 5 with the ring case.
Show solution
The chain has a spanning tree rooted at UAV 1, so (A1) holds; \(H\) is lower-triangular with eigenvalues \(1\) (all equal), but the transient is a chain of first-order lags, so UAV 5 sees a reference change delayed by roughly \(4/k_\xi\) s and with a fourth-order smoothed shape; with 10 % packet loss each hop adds expected delay. Slot errors of UAV 5 at turn entry are several times larger than on the ring; the pinned ring with \(\lambda_{\min}(H)=0.268\) is slower per mode but has no serial delay.
